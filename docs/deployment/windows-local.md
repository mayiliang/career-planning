# Windows 本地单机版手册

本方案面向只在自己 Windows 电脑上使用 Career Atlas 的场景。它位于独立分支 `codex/windows-local-desktop`，不会改变 `main` 分支。

## 使用结果

首次安装后，日常使用只需要双击桌面的“Career Atlas”：

1. 启动器先检查本地服务是否已经运行。
2. 未运行时，使用生产构建在后台静默启动一个 Node.js 进程。
3. 服务就绪后，主入口使用现有 Chrome 配置打开普通最大化窗口，因此 Chrome 中已经安装的 KIMI 等扩展仍可使用。
4. 重复双击不会启动多个服务进程。

安装器还会创建“Career Atlas Immersive”入口，使用 Microsoft Edge 应用模式打开没有地址栏和标签栏的沉浸窗口。两个入口共享同一个本地服务、数据库和配置，不会产生两套学习数据。桌面、开始菜单、应用窗口与浏览器标签会使用 Career Atlas 自有的“能力地图 + 成长方向”图标，不再借用浏览器图标。

日常启动不会执行依赖安装、代码构建、数据库迁移命令或 Docker 命令。数据库迁移与知识内容同步由服务在启动时自动完成。

## 首次安装

### 前置条件

- Windows 10 或 Windows 11。
- Node.js 20 或更高版本，推荐 Node.js 22 LTS。
- 首次安装期间可以访问 npm 软件包源。
- 项目代码应停留在本地磁盘上，便于以后从同一分支升级。

不需要安装 Docker Desktop。安装脚本会优先使用现有 pnpm；如果找不到，则通过 Node.js 自带的 Corepack 调用仓库声明的 pnpm 版本。

### 安装操作

双击：

```text
windows\Install-Career-Atlas.cmd
```

安装程序会依次完成：

1. 检查 Node.js 版本。
2. 安装并锁定项目依赖。
3. 创建一次生产构建。
4. 生成只包含生产依赖的独立运行副本。
5. 在目标数据目录为空时，复制仓库现有的 `data`；原目录不会被移动或删除。
6. 在目标配置不存在时，复制现有 `.env.local`；密钥内容不会打印到安装日志。
7. 创建桌面和开始菜单快捷方式。
8. 完成健康检查后打开应用。

安装与升级会严格按仓库锁文件对齐依赖；即使本机先后使用过不同的 pnpm 运行版本，也不会因为需要确认重建依赖目录而卡在无人值守提示上。

## 文件位置

默认安装根目录：

```text
%LOCALAPPDATA%\CareerAtlas
```

| 目录 | 内容 | 升级时是否覆盖 |
| --- | --- | --- |
| `app` | 当前生产运行文件 | 是，以完整新版本替换 |
| `rollback-app` | 上一次生产运行文件 | 下一次成功升级时轮换 |
| `data` | SQLite 数据库、自动备份和恢复文件 | 否 |
| `config` | `.env.local` 与 AI 配置 | 否 |
| `logs` | 后台服务启动与错误日志 | 否 |
| `state` | 当前安装版本和本机进程身份 | 会更新 |
| `tools` | 静默启动器 | 会更新 |
| `assets` | Career Atlas 快捷方式图标 | 会更新 |

服务只监听 `127.0.0.1:41731`。页面和 API 使用同一端口，不向局域网或公网开放，也不需要 Windows 防火墙入站规则。

## 数据与配置迁移

第一次安装时，如果 `%LOCALAPPDATA%\CareerAtlas\data\career-atlas.db` 尚不存在，安装器会复制仓库 `data` 目录中的现有数据。以后升级时，无论源码目录中有什么内容，都不会用它覆盖安装目录中的个人数据。

配置采用相同规则：只在安装目录没有 `.env.local` 时复制一次。以后修改 AI 密钥时，应修改：

```text
%LOCALAPPDATA%\CareerAtlas\config\.env.local
```

未配置 AI 密钥时，资料阅读、Markdown 笔记、站内练习、路线、打卡和本地备份仍可使用；依赖外部模型的整理、提示或评分会按系统已有规则安全降级。

### 导入以前下载的个人数据 JSON

1. 双击桌面的“Career Atlas”，进入“系统与数据”。
2. 在“备份与恢复”中找到“导入个人数据 JSON”，选择之前由系统下载的 `.json` 文件。
3. 等待本地校验完成，查看文件导出时间、知识点匹配情况以及各类数据导入前后的数量变化。
4. 确认无误后点击“按预览结果导入”。系统会先自动创建一份数据库快照，然后一次性恢复个人数据。

JSON 导入不会替换当前版本的知识正文。能按编号匹配的知识点会恢复个人进度；当前版本新增、但旧文件中没有的知识点会保持现状；旧文件中已经不存在于当前版本的知识点进度会跳过并显示警告，其历史笔记仍会保留。格式错误、内容损坏、版本不支持、记录引用不完整或写入失败时，现有数据不会被部分覆盖。

## 日常使用

双击桌面的“Career Atlas”会在 Chrome 普通最大化窗口中打开，保留扩展工具栏、侧边栏和右键菜单。如果 KIMI 第一次没有出现在本地页面，请在 Chrome 的扩展设置中允许它访问 `http://127.0.0.1:41731`。需要隐藏浏览器界面专注学习时，双击“Career Atlas Immersive”，它会使用 Edge 应用模式打开。服务尚未运行时，两个入口都会先等待数秒完成数据库检查和内容同步。

关闭应用窗口不会删除任何数据。后台服务会继续运行，占用很少的本机资源；Windows 注销或重启后进程会自然结束，下次双击时自动恢复。

## 升级

确认项目代码已经切换到需要安装的版本，然后双击：

```text
windows\Update-Career-Atlas.cmd
```

升级流程会先构建一个新的暂存版本，停止经过进程号和启动时间双重核对的旧服务，再切换运行目录。个人数据与配置不参与替换；旧应用文件保留在 `rollback-app`，避免构建失败或文件切换失败时破坏当前可用版本。

新版本会使用不含 pnpm 目录链接的生产依赖布局，确保后续升级和卸载都能可靠清理运行文件。第一次从旧布局升级时，无法安全删除的旧回滚目录会被隔离为 `legacy-runtime-*`，不会阻断升级，也不会影响个人数据；后续版本不再产生这类目录。

升级脚本不会自动执行 `git pull`，也不会切换分支，避免未经确认改变源码。

## 卸载

双击：

```text
windows\Uninstall-Career-Atlas.cmd
```

默认卸载只删除应用运行文件、日志、进程状态和快捷方式，保留 `data` 与 `config`。以后重新安装可以继续使用原来的学习记录和配置。

彻底删除个人数据属于不可恢复操作，因此普通卸载器不会执行。确实需要彻底删除时，可以在 PowerShell 中显式运行 `uninstall-local.ps1 -RemoveData`，并按提示输入 `DELETE`。

## 故障处理

### 双击后没有出现窗口

查看最新日志：

```text
%LOCALAPPDATA%\CareerAtlas\logs
```

启动器遇到错误时会显示提示框，并给出对应错误日志位置。常见原因包括 Node.js 被卸载、41731 端口被其他程序占用或安装目录不完整。

### 端口已被占用

本地版不会结束身份不匹配的进程。如果 41731 已被其他软件使用，Career Atlas 会拒绝启动并保留错误日志，避免误杀其他程序。

### 数据恢复

如果手中是系统下载的 `.json` 文件，使用“导入个人数据 JSON”；导入完成后立即生效，不需要重启。如果需要把整个数据库恢复到某个时间点，则在设置页预览自动快照后执行“恢复”；数据库快照恢复会暂存文件，并要求重新启动本地服务。不要直接覆盖正在使用的 SQLite 数据库。

### 源码目录被移动

日常桌面快捷方式和卸载器都使用 `%LOCALAPPDATA%` 中的独立副本，因此源码目录移动后仍能打开或卸载。只有“升级”依赖原项目路径；在新位置重新运行安装器即可刷新升级快捷方式。

## 安全边界

- 服务固定绑定本机回环地址，不可通过其他电脑访问。
- AI 密钥只存在于本地配置文件，不进入前端构建，也不会显示在健康检查中。
- 安装器不会删除原始 `data`，不会在升级时覆盖个人数据库。
- 停止后台服务前会同时核对记录的进程号、进程名称和启动时间，降低进程号复用导致误终止的风险。
- 静态页面使用 Fastify 官方静态文件组件，并固定到已修复非规范路径授权绕过问题的版本。
