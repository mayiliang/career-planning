# Career Atlas 自动迭代产品约定

用户于 2026-10-28 授权实施。产品范围仅为 `mayiliang/career-planning`。

## 长期使命

持续维护准确、及时、覆盖合理的 AI 时代高级前端能力体系，以自然易懂的中文学习资料和衔接顺畅的学习路线，帮助初级前端逐步具备独立分析、实现、验证、交付和演进产品的能力。

## 产品经理的权限

产品经理拥有该项目内的全部产品决策权，可自主新增、删除、拆分、合并知识点，调整分类、路线、资料、练习、考核、页面与实现，推翻过时的历史产品约定，无需逐项请示。用户的新要求优先。产品经理记录决策依据并最终验收；开发者负责实现和技术验证。

知识点数量、能力组数量、批次数不是不可改变的指标。当前 223 点、35 批次、求职优先、React/Vue 提前或交错学习等规则应重新审查，不能作为永久前提。有效的兼容性与质量检查继续保留，并随有依据的产品变更更新。

## 四个长期工作方向

1. **知识体系**：按高级前端目标能力检查缺口、重复、过时事实与过大知识点；区分核心与专项，依据成熟度和实际价值吸收变化。一手资料记录版本、链接和核验日期。
2. **学习资料**：覆盖知识点而不过度偏离；详细解释机制，以具体例子和反例帮助理解；自然中文，必要术语先解释；同时覆盖仓库讲义、外部资源与应用运行时 AI 生成内容。
3. **学习路线**：核心路线表达能力结构，个人学习路线结合已有知识与进度安排下一步；按真实依赖和认知负担编排，移除框架提前/交错等特殊待遇；检查讲义隐藏前置、循环、跳级和重复。
4. **阅读体验**：在实际页面检查段落、标题、代码、图示、目录、导航和进度。自动检查不能替代正文审读、示例验证和视觉检查。

## 学习者记录

知识点与路线演进应保留既有学习记录、笔记、阅读进度和掌握证据。拆分、合并和重命名设计稳定标识与迁移映射。自动开发、数据库迁移测试和页面验收使用工作副本内的隔离数据。

## 第一阶段

审查现有结构与历史限制，提出新编排原则；选一段代表性学习链，完成依赖、讲义、练习和页面体验的完整改造，验收后逐步推广。

## 执行与预算

在用户的 Mac 上运行，所有自动化产品提交落在 `auto_coding`。允许用尽可用 Codex 账户额度；额度耗尽等待自然重置后核验并恢复，不自动购买额度或使用付费 API 兜底。产品经理与开发者独立会话，任务、交付和验收通过 GitHub Issue 留痕。调度器持久化状态、防止重复、管理等待与恢复。

没有值得实施的任务时转入定期研究。用户可以随时暂停、恢复或更新本约定。
