## 2026-10-28：重新审查知识结构和学习路线

- 依据：用户明确要求移除 React/Vue 提前学习等特殊待遇，重构路线，让知识连接自然，并持续改进中文讲解与排版。
- 现状证据：`apps/server/src/services/knowledge-relations.service.ts` 中有提前安排、框架交错与固定 35 批次的逻辑；`packages/content-parser/src/parser/content.test.ts` 固定检查 223 点。
- 决定：这些是可修订的历史产品选择，不是新路线的不可变条件。先由产品经理研究真实依赖和一段代表性学习链，再通过 Issue 逐项交付。
- 保留要求：知识标识与个人学习记录的兼容，内容事实准确，中文可读性，真实验证。
- 重新评估条件：实际学习链的审读、示例或页面验收揭示新的认知障碍；或用户更新产品目标。

后续决定记录日期、问题、证据、选择、影响和重新评估条件，避免仅为保持活跃而反复翻转方案。
