# React / Vue 入口合同与迁移边界

Issue #6；初次审读 2026-11-01，恢复实施及验证 2026-11-09（Asia/Shanghai）。本报告只覆盖 REACT-01、VUE-01。全局框架交错顺序仍为待替换的兼容现状。

## 入口决定与依据

REACT-01 的硬前置为 JS-01、JS-03、WEB-01；VUE-01 为 WEB-01。硬前置表示本篇确实使用该基础能力，不是强制完成整篇上游考核的权限门禁。已有基础者可以直接阅读和练习。页面展示学习状态，不把资料查阅或阅读阈值当作掌握证明。

JS-06 改为推荐补读静态模块章节，并保留 RELATED 关系：两个入口只使用静态 import/export，主讲义已就地解释。JS-06 自己的直接前置是 JS-05，继续递归会引入 JS-04 与闭包；若保留整篇 JS-06 硬门槛，会把动态导入、错误与取消都提前要求。这个需求不来自入口练习，故不采用。也不为了通过传递冗余检查而删掉 React 真正直接使用的闭包基础。

TS-03 不再是硬前置：组件输入类型和 useState 的类型实参只需要读懂现成声明，不要求自行设计泛型、keyof 或索引访问。TS-01 推荐补读；类型记号在正文解释。Vue 的 ref、v-if、事件、模板解包和 scoped 的最小作用机制在本篇解释，VUE-02/03/04 是深入方向，不倒置为入口前置。React 的 ref 只保存回调队列，布局 Effect 只观察提交，不要求提前学习 REACT-04 的订阅模型。

### REACT-01 概念—章节—练习—基础

| 概念 | 正文章节 | 练习要求 | 基础与关系 |
| --- | --- | --- | --- |
| 函数组件、props、JSX | 组件先返回一份界面描述 | 识别事件绑定与输出 DOM | WEB-01 硬前置：元素和按钮；类型记号就地解释 |
| render / commit / 绘制 | 一次更新分成触发计算和提交；固定回调实验 | 日志按阶段分栏，不按次数评分 | HTML/DOM 基础；布局 Effect 最小用途就地解释 |
| 快照与闭包 | 快照属于一次渲染而不是整个组件 | 两个回调 snapshot 都来自预约那次 render | JS-01 硬前置：函数作用域、闭包 |
| 值式 / updater / 混合队列 | 三次加一；替换值与更新函数；批处理 | 一次点击内三次请求与三次独立点击分别验证 | JS-01 中的函数与参数；队列机制本篇教授 |
| 可控延迟 | 用手动释放回调固定观察顺序 | 先预约、加三、两次释放；值式 3/1/1，函数式 3/4/5 | ref 与函数数组就地解释；不用真实毫秒竞争 |
| 纯度 / 输入污染 | 用相同输入复现纯度错误；纯渲染允许 React 重新计算 | 同输入调用两次，比较返回值和原数组 | JS-03 硬前置：共享引用、浅拷贝与不可变更新 |
| Strict Mode | Strict Mode 的额外调用不是额外点击 | 事件次数与诊断调用分开 | 本篇解释；不把某个模式的 render 次数写成评分公式 |
| 工程入口 | 建立可复现的练习工程；学习前先确认 | 固定 package、tsconfig、HTML、main、App | 静态模块就地解释；JS-06 推荐补读 |
| key、派生状态、并发与 Hydration | 原有对应章节保留 | 本次固定首考不扩张到完整状态架构 | 后续深入与相关知识；Vue 对照为选读 |

### VUE-01 概念—章节—练习—基础

| 概念 | 正文章节 | 练习要求 | 基础与关系 |
| --- | --- | --- | --- |
| HTML 到组件 | 沿三个文件找到页面入口；固定工程 | HTML→main.ts→App.vue→ReadingCard.vue；错误 mount 反例 | WEB-01 硬前置：容器、语义元素和按钮 |
| SFC 编译 | SFC 把同一组件的代码放在一起 | 说明模板、逻辑和样式由谁处理 | 静态 import/export 本篇补齐；JS-06 推荐 |
| 模块与实例 | 模块执行一次与每个实例执行不是一回事 | 第一张展开不影响第二张 | ref(false)、模板解包、事件、v-if 本篇解释 |
| 别名 | 别名需要让构建工具和类型工具指向同一处 | 删 Vite alias 时 typecheck 通过但 build 失败 | JSON 配置与路径按本篇文件复现 |
| 公开环境 | 环境变量进入客户端以后就是公开配置 | 唯一 .env 提供 /api 与 false；删地址后重启开发服务及重建预览均报错；恢复后两处恢复 | 字符串比较；不把 VITE 前缀当保密机制 |
| CSS 作用域 | Scoped CSS 限制选择器不隔离整个世界 | 卡片内 h2 变绿、外部 h2 不变；删 scoped 后外部命中 | h2 选择器与 color 就地解释；层叠深入非必考 |
| 类型与生产 | 类型检查和构建各自回答不同问题 | 错误 minutes 字符串被类型检查拒绝，构建可成功 | 输入类型声明就地解释；不要求 TS-03 |
| 单变量复测 | 固定入口练习与单变量排错 | 仅第二张 minutes 30→45；第一张保持 25 | 本篇已教授的 prop 绑定，无 Router / React |
| 资源、代理、HMR | 保留原章节 | 延伸阅读；不要求无后端项目启动代理 | 明确替代配置不能覆盖入口实验别名配置 |

## 旧检查的去向

| 旧检查 | 新合同处理 | 承接现状 |

### 2026-11-10：环境文件协议勘误
