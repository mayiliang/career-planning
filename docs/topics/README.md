# 专题产出

这个目录用于存放学习过程中形成的可复用成果。专题不是课程摘抄，而是“原理 + 真实项目场景 + 实践结果 + 面试表达”的组合。

## 计划专题

| 阶段 | 文件 | 核心产出 |
| --- | --- | --- |
| 第 3-4 周 | `typescript-business-modeling.md` | 业务类型建模、20 道面试题、代码样例 |
| 第 5-6 周 | `react-state-performance.md` | 状态设计、性能诊断、优化记录 |
| 第 7-8 周 | `enterprise-admin-patterns.md` | 中后台业务对象、审核流与权限模式 |
| 第 9-10 周 | `h5-hybrid-playbook.md` | H5 适配、Hybrid 调试与性能报告 |
| 第 11-12 周 | `frontend-engineering-quality.md` | 构建、测试、发布与质量保障 |
| 第 13-14 周 | `aiui-component-design.md` | 组件 API、设计取舍与示例 |
| 第 11-16 周 | `api-tooling-and-ai-workflow.md` | API 工具设计和 AI 辅助研发流程 |
