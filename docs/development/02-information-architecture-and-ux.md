# 信息架构与交互

更新时间：2026-08-03

## 1. 主导航

```text
学习台        当前知识点、统一推荐、今日打卡、路线概览
知识体系      能力树/列表、关系、搜索、状态和恢复入口
笔记中心      按体系排序的 Markdown 笔记与版本
日历记录      历史打卡、面试、复盘等记录；不强制排课
掌握挑战      从知识详情进入的可选 M1～M4 任务
求职与项目    岗位反馈、项目证据
系统与数据    AI、备份、导入、诊断
```

## 2. 学习台

- 首屏核心只有“当前正在学”。有当前点时显示状态、笔记进度和继续按钮；没有时显示与路线参考完全一致的建议起点。
- 今日打卡是独立动作，可关联当天真正学习的多个知识点。
- 路线参考说明“为什么推荐”，不制造第二套相互冲突的顺序。
- 已学完后提供“学习下一个”；存在唯一后续就直接进入，只有 `TRACK_CHOICE` 才打开方向选择。

## 3. 知识详情布局

桌面端使用密度适中的内容区：资料与活动可并排，笔记编辑与 AI 候选稿并排；同组卡片使用 CSS Grid 的拉伸对齐，内部内容自行流动。移动端全部转为单列。

页内标签：

1. 学习资料：统一 Markdown 阅读器、真实学习活动与站内练习区。
2. 我的笔记：编辑/分栏预览/只预览、保存、AI 整理和版本说明。
3. 掌握挑战：M 等级、理论/实践/混合模式和通过标准。

完成卡与下一步位于标签之后，确保资料、笔记、完成、路线形成自然顺序。

## 4. Markdown 体验

- 阅读区正文宽度与行距优先，不把大面积灰底当作布局。
- 表格和公式在自身区域横向滚动；代码块高对比并保持可复制。
- Mermaid 图形居中、按需加载，生成中显示骨架，语法错误显示在图形卡内。
- thinking 是 `<details>` 折叠区，标题明确写“模型提供，可能不完整”，与最终正文视觉分离；长内容在面板内部滚动、自动跟随最新输出，用户回看旧内容时暂停跟随，生成完成后自动收起。
- AI 流式正文有轻量光标；频繁 token 通过合并更新，不能造成整页闪烁和滚动跳动。

## 5. 掌握挑战体验

- 开始前说明可选、失败影响和帮助规则。
- 题目区先展示知识标签、明确题干、输入、必须输出、作答要求和指定格式，再展示资料定位。
- 帮助区保留渐进阶梯；AI 正文与 thinking 均用 MarkdownRenderer。
- 评分时底部提交栏显示真实阶段、已收字符和可折叠 thinking；完成后给逐题正确点、缺失、参考答案、资料依据和下一步。
- 已存在会话时恢复旧答案并显示“已继续上次挑战”，不是报 `Existing session in progress`。

## 6. 视觉规则

- 同一行的同级卡片由网格拉伸到相同轨道高度；差异过大的主从内容改为上下布局，并把从属任务横向排成等高卡片，不能留下无用途的大块空白。
- 页面最大宽度根据任务调整，阅读正文保持舒适行长，仪表盘使用更高空间利用率。
- 顶部说明优先采用紧凑工具栏或默认收起的渐进说明；标题、解释、返回按钮不能长期占用主体首屏。
- 颜色用于状态和层级，不用大面积低对比灰色占据页面。
- 弹窗统一使用可聚焦、可键盘关闭、有明确主次操作的对话框。
- 加载、空状态、错误、中止、恢复和成功都必须提供下一步动作。

## 7. 无障碍与响应式

- 所有按钮有可理解文本；纯视觉状态同时有文字。
- `aria-live` 只播报关键进度，不能为每个 token 触发朗读。
- 对话框管理焦点；折叠区使用原生 `details/summary`。
- 尊重 `prefers-reduced-motion`，关闭光标、脉冲和图形骨架动画。
- 720/850px 左右断点下切单列，操作按钮允许换行且保持可触达。
