# 测试与验收

更新时间：2026-08-04

## 1. 必跑命令

```bash
pnpm content:check
pnpm content:links:strict
pnpm test
pnpm lint
pnpm build
pnpm test:e2e
```

`pnpm content:links:strict` 是需要网络的独立资料链接检查。发布前必须执行，404/410 和无法确认都会阻断；日常离线开发可暂缓。

## 2. 内容门禁

- 20 个稳定能力组、223 个唯一知识点，编号、能力组、二级主题、分类和关系合法。
- 成熟度仅允许稳定/演进中/实验性；AI 关系独立；框架、厂商、平台和法域限制进入可多选适用标签；主修必修点必须有赛道 ID。
- 默认路线精确覆盖全员必修与 React、Agent/MCP 默认主修；任一硬前置都不得缺席或晚于依赖点。
- 每份当前资料自身的正文与本知识点直接相关度约 80% 以上；多份资料组合后覆盖定义、机制、适用条件、边界/失败和验证，且没有同点重复 URL。
- 每点具备中文主学习源；中文讲义使用精确锚点且本地独立主源达到最低完整性，并明确包含定义、机制、适用条件、边界/反例和验证信号。
- 七份逐点报告覆盖全部 223 点及每个当前 URL；当前映射没有未核验、低相关声明或未标删除的历史链接，英文资料只用于版本核验。
- 挑战题源只能来自标注资料；需推导时有依据和步骤。
- 学习活动有明确输入、输出、完成标准、资料位置和站内交付方式。
- 资料链接无已知失效地址，本地路径同时兼容 LF/CRLF 和三大桌面系统路径。
- 待完成项目只能是可选证据，不得被当作知识真源或首考隐藏前置。

## 3. 单元/服务测试

- 当前知识点、统一推荐、唯一后续、轨道选择、暂缓和恢复。
- 学习完成与 M 等级独立，打卡不依赖固定日程。
- 原始笔记版本不被 AI 覆盖；中止、超时、空流和本地降级安全。
- SSE 将 progress、thinking、delta、done、error 分离。
- Markdown 支持表格、任务、脚注、公式、Mermaid、thinking、代码高亮并阻止脚本链接。
- 掌握题合同、帮助资料定位、独立程度上限、评分 Schema 和服务端重算。
- 223 个知识点逐点生成与本点题源、首考最小产出和可验证合同绑定的站内练习；AI 不能覆盖本地结构门禁失败，本地 Worker 自检也不能单独证明代码语义正确。
- 所有本地中文讲义链接都能由服务端安全读取精确章节，并由学习资料、练习和挑战共用站内地址；目录穿越与无效锚点被拒绝。
- 导入、迁移、备份和恢复保持用户数据。

## 4. E2E 主流程

1. 空状态建议点与路线第一点一致。
2. 设置当前点、保存 Markdown 笔记、标记已学完、学习唯一下一点。
3. 打卡关联当天真实学习点。
4. 表格、公式、图形和 thinking 块在预览与阅读版正确显示。
5. 站内代码练习可编辑、运行、显示输出、保存并验证。
6. 从知识点资料打开本地中文讲义时进入站内精确章节，正文不串入相邻知识点。
7. 创建掌握挑战；已有会话无错误恢复；答案自动保存。
8. 渐进提示包含题目与资料内容，流式 UI 可中止。
9. 分支只在线路结束出现，暂缓/恢复行为符合语义。
10. 笔记中心默认体系排序，自定义排序和搜索可用。
11. 桌面卡片对齐、移动端单列、对话框键盘操作和关键空/错状态可用。

## 5. Markdown 性能验收

- 500 次短 token 更新不能产生 500 次同步 DOM 提交；最终文本必须完整。
- 相同快照命中有界缓存，缓存不无限增长。
- 无 Mermaid 时不加载 Mermaid 运行时；围栏闭合后才绘图。
- 异步旧图不得覆盖新输入；卸载后无定时更新。
- 长表格、公式、代码和图形只在局部横向滚动。
- 使用浏览器 Performance 验证输入时无持续长任务和明显滚动跳动。

## 6. 安全验收

- Markdown 原始 HTML、事件属性、`javascript:` 链接无法执行。
- Mermaid strict 模式，AI 和用户 Markdown 共用清洗器。
- API 密钥不进入前端包、响应或日志。
- 不可信代码不在宿主机或 Fastify 进程执行。
- 公网部署检查认证网关/TLS、API 回环绑定、SSE 代理配置和数据卷备份。

## 7. 验收记录

每次完整整改后在 `implementation-status.md` 记录实际命令、通过数量、已知外部依赖和日期。不得复制旧计数；测试数量变化时用最新输出更新。
