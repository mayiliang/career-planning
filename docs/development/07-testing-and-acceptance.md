# 测试与验收

更新时间：2026-10-13

## 1. 必跑命令

```bash
pnpm content:check
pnpm content:links:strict
pnpm test:unit
pnpm lint
pnpm build
pnpm test:e2e
```

`pnpm content:links:strict` 是需要网络的独立资料链接检查。发布前必须执行，404/410 和无法确认都会阻断；日常离线开发可暂缓。

`pnpm test:unit` 是 `pnpm test` 的别名，两者均覆盖四个工作区；浏览器回归单独运行 `pnpm test:e2e`。

## 2. 内容门禁

- 20 个稳定能力组、223 个唯一知识点，编号、能力组、二级主题、分类和关系合法。
- 成熟度仅允许稳定/演进中/实验性；AI 关系独立；框架、厂商、平台和法域限制进入可多选适用标签；主修必修点必须有赛道 ID。
- 默认路线精确覆盖 149 个全员必修与 React、Vue、Agent/MCP 默认主修点，并分成 35 个非空批次（每批 4～5 点）；路线页、学习台建议和详情下一步共用该索引，React/Vue 框架节点按并列阶段交错出现，任一硬前置都不得缺席或晚于依赖点。
- 路线批次只能包含真实知识点，不得出现复盘、综合实践、机动学习或其他无发布/验收合同的占位任务；专项点不得因旧数据库周次混入核心路线。
- 每份当前资料自身的正文与本知识点直接相关度约 80% 以上；多份资料组合后覆盖定义、机制、适用条件、边界/失败和验证，且没有同点重复 URL。
- 每点具备中文主学习源；中文讲义使用精确锚点且本地独立主源达到最低完整性，并明确包含定义、机制、适用条件、边界/反例和验证信号。
- 七份逐点报告覆盖全部 223 点及每个当前 URL；当前映射没有未核验、低相关声明或未标删除的历史链接，英文资料只用于版本核验。
- 挑战题源只能来自标注资料；需推导时有依据和步骤。
- 学习活动有明确输入、输出、完成标准、资料位置和站内交付方式。
- 资料链接无已知失效地址，本地路径同时兼容 LF/CRLF 和三大桌面系统路径。
- 待完成项目只能是可选证据，不得被当作知识真源或首考隐藏前置。

## 3. 单元/服务测试

- API 超时覆盖响应正文；HTTP 业务错误保留 requestId 与字段详情。
- SSE 覆盖跨片 UTF-8、CRLF、多行 data、无结尾空行、供应商结束标记、调用方取消、回调异常和读取器释放。
- 评分覆盖重复请求幂等、并发任务冲突、结果/知识点/审计的原子回滚、重评失败保留旧结果、取消与启动恢复；事务测试使用真实测试库。
- 挑战创建覆盖题目缺失、空正文、M4 缺少变式、题目写入失败与同时创建；失败不得留下空会话，重试与恢复保留完整五题合同。
- 提交必须等待全部答案成功保存；保存失败不锁卷，评分或提交响应失败时保留当前输入与主错误。同题写入顺序执行，失焦和提交复用相同进行中快照；空卷和空白答案不得锁定。
- 服务端同时保存同一题只新增一行；提交检查和状态变更在事务中完成，晚到答案不能修改已锁定的答卷。提示互斥，自检记录必须对应实际执行的代码，销毁后忽略迟到流内容。
- 路线分支使用状态快照与批量目标查询，查询次数保持有界；状态变化立即生效。暂缓失败时回滚选择记录和全部目标，已学完状态、完成时间与掌握记录受到保护。
- 考核 JSON 与 SSE 最终结果通过同一公开 Schema 校验；内部模型响应、用量、重算字段和提示版本不得因直接返回数据库记录进入响应。
- 知识点切换覆盖读取与保存反馈的身份隔离；原文保存失败时，AI 整理与学习完成不得继续提交；旧失败回调不得改写新草稿或旧知识点的存储键。
- 应用工厂可以独立组装并注入请求；参数错误统一返回 400，内部异常保持统一错误响应。
- 自动备份拒绝无效的定时频率、记录定时失败且不重叠执行，关闭时等待正在进行的任务。
- 笔记搜索、资料与岗位切换时，旧请求不得更新新页面的成功、错误或 loading 状态。

- 当前知识点、统一推荐、唯一后续、轨道选择、暂缓和恢复。
- 学习完成与 M 等级独立，打卡不依赖固定日程。
- 原始笔记版本不被 AI 覆盖；中止、超时、空流和本地降级安全。
- 原文变化与并发整理使旧快照失效；候选稿、核对信息与版本历史一起提交或回滚。新候选稿不能替换已采用的阅读内容，采用需核对候选版本；重复保存和采用不新增相同历史。
- 采用操作与整理操作覆盖跨页迟到反馈、晚于原文保存的响应及编辑器作用域销毁；原文未保存时不能采用旧候选稿。
- 保存途中将文本撤回至旧快照再离开时，最终文本仍须保留本地草稿，不能被中间写入的晚到完成状态吞掉。
- SSE 将 progress、thinking、delta、done、error 分离。
- Markdown 支持表格、任务、脚注、公式、Mermaid、thinking、代码高亮并阻止脚本链接。
- 掌握题合同、帮助资料定位、独立程度上限、评分 Schema 和服务端重算。
- 223 个知识点逐点生成与本点题源、首考最小产出和可验证合同绑定的站内练习；AI 不能覆盖本地结构门禁失败，本地 Worker 自检也不能单独证明代码语义正确。
- 所有本地中文讲义链接都能由服务端安全读取精确章节，并由学习资料、练习和挑战共用站内地址；目录穿越与无效锚点被拒绝。
- 导入、迁移、备份和恢复保持用户数据。
- CSV 岗位导入存在无效行时不得部分写入；备份恢复预览必须使用真实完整性校验与当前数据对比；个人数据导出不得包含系统密钥或知识正文；JSON 导入必须拒绝损坏/错版文件、显示新旧知识点和数量差异、确认同一文件、自动备份，并在中途失败时整笔回滚。

## 4. E2E 主流程

1. 空状态建议点与路线第一点一致，并展示一个真实活动的固定输入、交付物、完成判定和开始入口。
2. 设置当前点、保存 Markdown 笔记、标记已学完、学习唯一下一点。
3. 打卡关联当天真实学习点。
4. 表格、公式、图形和 thinking 块在预览与阅读版正确显示。
5. 站内代码练习可编辑、运行、显示输出、保存并验证。
6. 从知识点资料打开本地中文讲义时进入站内精确章节，正文不串入相邻知识点。
7. 创建掌握挑战；已有会话无错误恢复；答案自动保存。
8. 渐进提示包含题目与资料内容，流式 UI 可中止。
9. 分支只在线路结束出现，暂缓/恢复行为符合语义。
10. 笔记中心默认体系排序，自定义排序和搜索可用。
    搜索慢响应不能覆盖新结果；岗位详情组件复用时必须跟随路由参数重新读取。
11. 桌面卡片对齐、移动端单列、对话框键盘操作和关键空/错状态可用。
12. 路线页恰有 35 个批次，首点为 `JS-01`，每批都能进入真实知识点页面，且不存在空批次或泛化任务文案。
13. AI 未配置或连接失败时，完整掌握挑战在创建答卷前停止，说明数据边界并提供设置入口；模拟可用时会话创建、恢复和取消仍正常。
14. 岗位可用键盘创建；中英文 CSV 必须先预览、全部有效后才能导入。
15. 笔记无需手动点击即可自动保存；服务端失败后本地草稿在刷新后仍可恢复，且不会每 1.2 秒无限重试；恢复对话框展示当前、恢复后和差异，关闭后焦点回到预览按钮。
16. 个人数据 JSON 选择后先完整校验和预览，取消后焦点回到“选择 JSON 并预览”，确认导入由服务端再次核对同一文件。
17. 跳到主要内容、对话框 Tab 循环/Escape/焦点恢复及 390px 窄屏无页面级横向溢出均通过。

## 5. Markdown 性能验收

- 500 次短 token 更新不能产生 500 次同步 DOM 提交；最终文本必须完整。
- 相同快照命中有界缓存，缓存不无限增长。
- 无 Mermaid 时不加载 Mermaid 运行时；围栏闭合后才绘图。
- 异步旧图不得覆盖新输入；卸载后无定时更新。
- 长表格、公式、代码和图形只在局部横向滚动。
- 使用浏览器 Performance 验证输入时无持续长任务和明显滚动跳动。

## 6. 安全验收

- Markdown 原始 HTML、事件属性、`javascript:` 链接无法执行。
- Mermaid strict 模式，AI 和用户 Markdown 共用清洗器。
- API 密钥不进入前端包、响应或日志。
- 不可信代码不在宿主机或 Fastify 进程执行。
- 公网部署检查认证网关/TLS、API 回环绑定、SSE 代理配置和数据卷备份。

## 7. 构建与发布预算

- 生产构建默认不得输出 `.map`；只有显式设置内部调试变量时允许生成。
- 构建从 Vite manifest 计算首屏 JavaScript、首屏 CSS、最大常规分块、懒加载 TypeScript 编译器和全部 JavaScript 体积，任一超出仓库预算即失败。
- E2E 使用独立临时数据目录并在结束后清理；专用端口已被占用时必须立即失败，不得连到旧测试服务后产生假通过。
