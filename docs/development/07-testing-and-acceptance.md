# 测试与验收

更新时间：2026-08-03

## 1. 必跑命令

```bash
pnpm content:check
pnpm test
pnpm lint
pnpm build
pnpm test:e2e
```

`pnpm content:links` 是需要网络的独立资料链接检查。发布前必须执行，日常离线开发可暂缓。

## 2. 内容门禁

- 20 个领域、219 个唯一知识点，编号、领域和关系合法。
- 每点资料数量、中文必读覆盖、中文讲义锚点、英文核验标签和资料覆盖范围有效。
- 挑战题源只能来自标注资料；需推导时有依据和步骤。
- 学习活动有明确输入、输出、完成标准、资料位置和站内交付方式。
- 资料链接无已知失效地址，本地路径同时兼容 LF/CRLF 和三大桌面系统路径。

## 3. 单元/服务测试

- 当前知识点、统一推荐、唯一后续、轨道选择、暂缓和恢复。
- 学习完成与 M 等级独立，打卡不依赖固定日程。
- 原始笔记版本不被 AI 覆盖；中止、超时、空流和本地降级安全。
- SSE 将 progress、thinking、delta、done、error 分离。
- Markdown 支持表格、任务、脚注、公式、Mermaid、thinking、代码高亮并阻止脚本链接。
- 掌握题合同、帮助资料定位、独立程度上限、评分 Schema 和服务端重算。
- 练习必须先满足站内执行和本地确定性检查，AI 不能覆盖失败。
- 导入、迁移、备份和恢复保持用户数据。

## 4. E2E 主流程

1. 空状态建议点与路线第一点一致。
2. 设置当前点、保存 Markdown 笔记、标记已学完、学习唯一下一点。
3. 打卡关联当天真实学习点。
4. 表格、公式、图形和 thinking 块在预览与阅读版正确显示。
5. 站内代码练习可编辑、运行、显示输出、保存并验证。
6. 创建掌握挑战；已有会话无错误恢复；答案自动保存。
7. 渐进提示包含题目与资料内容，流式 UI 可中止。
8. 分支只在线路结束出现，暂缓/恢复行为符合语义。
9. 笔记中心默认体系排序，自定义排序和搜索可用。
10. 桌面卡片对齐、移动端单列、对话框键盘操作和关键空/错状态可用。

## 5. Markdown 性能验收

- 500 次短 token 更新不能产生 500 次同步 DOM 提交；最终文本必须完整。
- 相同快照命中有界缓存，缓存不无限增长。
- 无 Mermaid 时不加载 Mermaid 运行时；围栏闭合后才绘图。
- 异步旧图不得覆盖新输入；卸载后无定时更新。
- 长表格、公式、代码和图形只在局部横向滚动。
- 使用浏览器 Performance 验证输入时无持续长任务和明显滚动跳动。

## 6. 安全验收

- Markdown 原始 HTML、事件属性、`javascript:` 链接无法执行。
- Mermaid strict 模式，AI 和用户 Markdown 共用清洗器。
- API 密钥不进入前端包、响应或日志。
- 不可信代码不在宿主机或 Fastify 进程执行。
- 公网部署检查认证网关/TLS、API 回环绑定、SSE 代理配置和数据卷备份。

## 7. 验收记录

每次完整整改后在 `implementation-status.md` 记录实际命令、通过数量、已知外部依赖和日期。不得复制旧计数；测试数量变化时用最新输出更新。
