# 产品需求文档

## 1. 产品定义

Career Atlas 是面向一名有 5 年经验的 React/Umi 前端工程师的个人成长系统。主线是建立可验证的高级前端能力，支线是管理杭州前端求职过程。

产品不把“读完一篇文章”当成进步。它必须把每个知识点串成下面的闭环：

```text
选择知识点 -> 阅读资料 -> 形成笔记/证据 -> 自评掌握
-> 严格考核 -> 初试通过 -> 7 天复测 -> 自动标记已掌握
-> 月度抽测与项目迁移
```

## 2. 产品目标

1. 把 219 个知识点变成可搜索、可关联、可学习、可考核的结构化数据。
2. 用知识图谱展示领域、知识点、前置依赖、项目场景和薄弱项。
3. 允许用户在网页中完成问答、试题、代码和项目型考核。
4. 由大模型按严格评分协议评判主观题，客观题与代码测试由程序确定性评分。
5. 考核流程完成后自动更新知识点状态并安排复测。
6. 用日历统一管理学习、考核、复测、求职投递和面试。
7. 保留岗位、公司、简历、项目资产、面试反馈和技能缺口等求职支线。
8. 所有用户数据保存在本机，可完整导入、导出、备份和恢复。
9. 通过真实项目完整经历 Vue 3 项目的脚手架、Composition API、路由、状态管理、组件开发、测试、构建和发布流程，并保留可学习的开发说明。

## 3. 非目标

- 不做多用户、组织、社交、排行榜或云同步。
- 不做课程交易平台或公开视频平台。
- 不让模型在没有结构化证据时直接修改“已掌握”状态。
- 不在浏览器保存 DeepSeek API Key。
- MVP 不执行任意系统命令，也不允许考核代码访问网络和宿主文件。

## 4. 用户角色

只有一个角色：系统所有者。

系统所有者可以维护内容、参加考核、修改计划、打卡、管理求职数据、配置模型、导入导出和查看全部本地记录。

## 5. 核心领域对象

- 知识领域：十个一级能力领域。
- 知识点：稳定编号、资料、考核说明、通过标准和状态。
- 学习投入：资料、练习、项目、首次考核和复测五阶段预计分钟数。
- 知识关系：前置、包含、关联、项目应用、同类比较。
- 学习资料：链接、本地 Markdown、项目文件引用、个人笔记、视频、实验、规范或真实项目片段；形式不限，但必须能够覆盖该知识点的核心机制、边界和通过标准。
- 考核定义：题型、评分维度、否决项和通过阈值。
- 考核会话：题目、回答、模型反馈、确定性测试、分数与结果。
- 计划事件：学习、考核、复测、投递、面试、复盘。
- 打卡记录：完成时间、时长、笔记和证据。
- 岗位：公司、薪资、方向、技术栈、技能差距和状态。
- 求职活动：投递、沟通、笔试、面试、Offer、拒绝和跟进。
- 项目资产：代表项目、问题、方案、结果、证据和简历表达。

## 6. 知识与学习模块

### KN-01 内容导入

- 首次启动导入 `docs/knowledge/knowledge-base/*.md`。
- 保留知识编号、标题、两个勾选状态、资料、严格考核和通过标准。
- 解析可选的五阶段预计耗时；缺省时按领域使用稳定默认值，所有分钟数必须为正整数。
- 重复导入按知识编号更新内容，不覆盖用户状态、笔记和考核历史。
- 显示导入预览：新增、更新、冲突、忽略。

### KN-02 知识清单

- 按领域、状态、难度、周次、项目和关键词筛选。
- 支持列表和紧凑矩阵两种视图。
- 状态至少包含：未开始、学习中、自评掌握、初试通过待复测、已掌握、需重学。
- 知识详情显示资料、个人笔记、考核要求、历史成绩、下一计划和关联项目。
- 知识详情同时显示首次掌握总耗时与五阶段拆分，列表支持比较预计投入。

### KN-03 知识图谱

- 领域是一级节点，知识点是二级节点，项目和资料可作为可切换图层。
- 支持前置依赖、相互关联、项目应用和技能缺口关系。
- 节点颜色表达掌握状态，双环表达“自评”和“严格考核”两个维度。
- 点击节点打开右侧上下文面板，不强制跳页。
- 支持聚焦学习路径、搜索定位、缩放、领域折叠和未掌握路径高亮。

### LEARN-01 学习工作区

- 左侧为知识点目录，中间为学习内容，右侧为笔记、计划和证据。
- 可打开外部官方资料，但本地笔记和 Markdown 直接在站内阅读。
- 每个知识点至少提供 2 个可直达资料链接，优先官方文档、标准、规范和权威课程；外链必须安全地在新标签打开。
- 支持 Markdown 编辑、代码块、高亮、清单、图片和本地附件。
- “自评已掌握”操作必须要求填写一句不看资料的总结或提交一个证据。
- 自评不会绕过严格考核。

## 7. 考核模块

### ASMT-01 考核创建

- 从知识点详情发起首次考核、7 天复测或月度抽测。
- 系统根据知识点的资料、严格考核、通过标准和历史薄弱项生成考卷。
- 默认题型组合必须有学习过渡：资料定位、概念解释、小例子推导、受限排错和学习复述。首次考核只允许从学习资料直接查到或一跳推导，不得直接跳到大跨度项目论文式问题；复测和月度抽测才逐步增加迁移范围。
- 生成后的题目和评分 rubric 固化，提交前不能查看参考答案。

### ASMT-02 答题

- 支持单选、多选、填空、长回答、代码、文件/项目证据和口述文本。
- 会话可自动保存，刷新后恢复。
- 闭卷模式隐藏学习资料和历史答案，并记录开始、暂停和提交时间。
- 编码题提供编辑器、测试结果和超时状态。

### ASMT-03 评分与反馈

- 客观题和代码测试先由程序评分。
- DeepSeek 只按固定 JSON 协议评价原理、边界、排障、方案和表达。
- DeepSeek 必须补充每道题的评审意见：对的地方、错误的地方、缺失项、参考答案、资料依据和下一步建议。
- 页面展示逐项得分、逐题评审、引用的回答证据、否决项、薄弱点、参考答案和下一步建议。
- 模型输出 schema 校验失败时不得改变知识状态，应允许重新评分。

### ASMT-04 自动状态更新

- 首次考核通过：状态变为“初试通过待复测”，自动创建 7 天后复测事件。
- 7 天复测通过：状态变为“已掌握”，记录掌握日期和证据。
- 月度抽测失败：状态变为“需重学”，取消当前“已掌握”有效标记并安排补学。
- 任一状态修改必须写入不可变审计记录。

## 8. 学习计划与日历

### CAL-01 日历视图

- 月、周、日和议程视图。
- 事件类型：学习、考核、复测、项目产出、投递、面试、复盘。
- 学习事件可关联一个或多个知识点；求职事件可关联岗位。
- 支持拖拽改期、重复规则、预计时长、优先级和提醒状态。
- 学习事件展示阶段负载、日容量、利用率和超载状态；默认日容量上限 390 分钟，按学习合同真实排期。

### CAL-02 计划导入

- 导入 `learning-tracker-template.csv` 的 64 周计划。
- 导入 `daily-6h30m-learning-schedule.csv` 作为默认时间块模板。
- 空库启动或重置学习进度时，从北京时间当天自动生成每周 7 天的连续计划；周一至周日都按五阶段预计分钟和项目整合任务拆分，没有休息日概念。
- 阶段任务按 15 分钟粒度排布，一个知识点允许跨天，禁止为了塞进当天而压缩考核。
- 重复导入必须预览差异并避免重复事件。

### CAL-03 打卡

- 学习事件可以标记：完成、部分完成、跳过、改期。
- 完成时记录实际时长、学习笔记、产出、困难和精力评分。
- 周复盘比较预计与实际时长，为后续个性化校准提供依据，但不得静默改写历史计划。
- 日历日期显示完成比例，不只显示连续天数。
- 支持日复盘、周复盘和计划完成率趋势。

## 9. 求职支线

### JOB-01 岗位管理

- 导入 `hangzhou-frontend-jobs-template.csv`。
- 列表和 Kanban 状态：收藏、待投、已投、沟通、笔试、面试、Offer、拒绝、放弃。
- 保存 JD、来源链接、薪资、地点、公司、技术栈和备注。
- 技能差距必须可以关联到知识点，反向影响学习优先级。

### JOB-02 求职活动

- 每次沟通、投递、笔试、面试和跟进都是一条活动记录。
- 面试活动支持记录问题、回答、反馈、结果和待补知识点。
- 面试和截止日期同步到学习日历。
- 支持每周投递漏斗和转化率，不把投递数量当作唯一目标。

### JOB-03 简历与项目资产

- 结构化维护代表项目、个人贡献、难点、方案、结果、证据和不同岗位版本。
- 从 `project-assets.md` 首次导入。
- 项目资产可关联知识点、岗位和面试题。
- 支持导出 Markdown，不要求 MVP 生成 PDF。

## 10. 系统与数据

### SYS-01 本地数据

- 数据库、证据附件和备份全部位于仓库可配置的 `data/` 目录。
- 默认不把 `data/`、`.env.local` 和上传文件提交 Git。
- 除用户主动触发的 DeepSeek 评分请求外，不向外发送本地数据。

### SYS-02 备份恢复

- 一键导出包含数据库 JSON、Markdown 笔记和附件清单的 ZIP。
- 导入前显示版本、记录数量和冲突策略。
- 自动备份采用轮换策略，默认保留最近 7 份。
- 恢复过程使用事务，失败不能留下半恢复状态。

### SYS-03 模型配置

- 显示 Provider、模型名、连接状态和最近一次错误。
- API Key 从服务端环境变量读取，页面只显示“已配置/未配置”。
- AI 不可用时允许学习、计划、打卡和求职模块正常工作。

### SYS-04 Vue 学习说明

- 项目内维护 `docs/vue-learning-guide.md`，随着阶段推进记录真实实现，而不是复制 Vue 入门教程。
- 至少覆盖项目创建、目录结构、SFC、Composition API、响应式、computed/watch、composable、Vue Router、Pinia、Vue Query、Element Plus、组件测试、E2E 和生产构建。
- 每个章节引用本项目中的真实文件，并说明它与用户熟悉的 React 思维模型有何相同和不同。
- 不为了展示 Vue API 而在业务代码里制造不必要的复杂度。

## 11. 关键用户旅程

### 第一次使用

1. 启动本地应用。
2. 系统检查数据库并展示内容导入预览。
3. 用户选择 64 周计划开始日期。
4. 系统生成知识点、图谱、学习事件和岗位模板。
5. 首页显示今天应做的事情，而不是空白仪表盘。

### 学习并掌握一个知识点

1. 从今日计划或知识图谱打开 `TS-02`。
2. 阅读资料、写笔记、完成示例。
3. 提交自评掌握证据。
4. 发起首次考核并提交。
5. 程序与 DeepSeek 评分，通过后进入待复测。
6. 7 天后从日历进入复测。
7. 复测通过后自动标记“已掌握”，图谱节点更新。

### 面试反馈反哺学习

1. 在岗位中记录一次面试活动。
2. 将未答好的问题关联到 `REACT-04`、`NET-01` 等知识点。
3. 系统提高相关知识点优先级并建议加入本周计划。
4. 补学、考核通过后回到岗位记录中查看技能差距关闭情况。
