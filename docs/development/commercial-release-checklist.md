# 商用品质发布检查表

更新时间：2026-08-20

这份检查表只接受可复核证据。“页面能打开”不等于可发布；每个阻断项必须给出自动化结果、演练记录或明确负责人。

## 一、当前可验收的产品闭环

- [x] 首次进入有一个具体学习任务，包含知识点、固定输入、交付物、完成判定和直接开始入口。
- [x] 学习资料、原始笔记、站内练习、学习完成和 M1～M4 掌握证据彼此不混淆。
- [x] React 与 Vue 在核心路线中同等优先，均有具体资料、练习和挑战合同。
- [x] AI 不可用时在答题前阻断完整挑战，并说明影响范围、数据去向和设置入口。
- [x] 岗位可手动创建；CSV 必须经过本地解析和服务端全批预览，存在无效行时不写入。
- [x] 笔记本地即时留稿、自动保存、失败可恢复；服务端保存状态对用户可见。
- [x] 备份恢复先校验并显示差异；个人数据 JSON 可导出和重新导入，导入前校验、预览、自动备份，并保证事务回滚。

## 二、每次候选版本的阻断检查

以下任一项失败，不得标记为可发布：

```bash
pnpm install --frozen-lockfile
pnpm content:check
pnpm test
pnpm lint
pnpm build
pnpm test:e2e
```

- 内容门禁必须覆盖 20 个能力组、223 个唯一知识点、学习资料锚点、题源闭环和逐点挑战合同。
- 端到端验收必须覆盖首次启动、学习完成、AI 预检、练习、掌握挑战恢复/取消、岗位创建/导入、笔记自动保存、键盘对话框、数据库恢复预览和个人数据 JSON 导入预览。
- 生产构建不得默认生成公开源码映射；首屏 JavaScript、CSS、懒加载 TypeScript 编译器、最大常规分块和总体积必须满足构建预算。
- 升级前必须用生产数据的脱敏副本演练迁移、创建快照、恢复预览、恢复和回滚。

## 三、可用性与无障碍

- 一个页面只使用一个一级标题；加载、空状态、错误、成功和取消都必须有明确下一步。
- 所有对话框支持 Escape、Tab/Shift+Tab 循环、背景滚动锁定和关闭后焦点恢复。
- 键盘用户可通过“跳到主要内容”绕过重复导航；按钮不得只用颜色表达状态。
- 390px 窄屏不得产生页面级横向滚动；200% 缩放后主要任务仍可完成。
- 发布前使用键盘、屏幕阅读器和 `prefers-reduced-motion` 各做一次人工冒烟，并记录浏览器、版本和结果。

## 四、安全、隐私和运维

- [x] API Key 仅由服务端读取，设置状态不回显密钥。
- [x] 浏览器 Worker 明示为本地自检，不作为安全沙箱或服务端证明。
- [x] 普通 API 有超时和可理解的失败反馈；流式 AI 请求保留独立取消与超时策略。
- [ ] 公网运营前接入账号、会话、权限、CSRF/速率限制和审计告警；当前产品只能在本机、私网或认证网关后使用。
- [ ] 确定发行许可证、第三方依赖许可清单、商标/内容授权和漏洞报告渠道。
- [ ] 运营方补充适用地区的隐私政策、数据处理协议、保留期限、删除请求和联系人。
- [ ] 对备份加密、密钥轮换、磁盘耗尽、数据库损坏、模型服务故障和回滚失败分别完成演练。

## 五、发布后的好评指标

首个商用试运行周期应至少记录以下可行动指标，不收集无目的行为数据：

- 首次进入到开始第一个具体任务的完成率和耗时；
- 笔记自动保存失败率、恢复草稿成功率；
- AI 预检失败原因分布，避免用户答完整份卷后才失败；
- CSV 预览错误率、修正后导入成功率；
- 挑战中止、恢复、帮助使用和评分争议率；
- 备份创建、恢复预览和演练成功率；
- 用户主动反馈中的高频阻塞、难懂文案和重复操作。

任何指标接入都必须先说明用途、保存周期和退出方式。单用户本地版应优先使用匿名、聚合、可关闭的本地统计，不默认接入第三方追踪器。
