# 实施路线

## 开发原则

- 每个阶段都必须可运行、可测试、可演示。
- 先建立数据与状态边界，再制作图谱和 AI。
- 不一次性生成整个系统后再调试。
- 每阶段结束更新 `docs/development/implementation-status.md`，记录完成项、测试、风险和下一阶段。
- 不删除或大规模改写现有职业规划内容；导入器适配现有格式。

## Phase 0：基线与脚手架

目标：建立可持续开发环境。

任务：

- 建立 pnpm workspace、Web、Server、Shared、Content Parser。
- 配置 TypeScript strict、ESLint、格式化、Vitest。
- 配置 `.gitignore`，排除 `data/`、`.env.local`、备份和临时运行目录。
- Fastify 提供 health API，Vue 应用显示本地服务状态。
- 建立 `docs/vue-learning-guide.md`，记录 Vue 项目创建、SFC、Composition API 和启动流程。
- 建立统一脚本和 README 启动说明。

退出标准：

- `pnpm install` 后能用一个命令启动 Web 和 Server。
- typecheck、test、build 全部通过。
- 浏览器不能读取服务端环境变量。

## Phase 1：数据库与内容导入

目标：把现有文档变成结构化本地数据。

任务：

- 实现 Drizzle schema、迁移和临时数据库测试。
- 实现 15 个知识文件解析、README 周次映射和领域综合考核解析。
- 实现三个 CSV 解析。
- 实现导入扫描、预览、冲突和事务提交 API。
- 实现启动时自动迁移、增量导入和空库计划生成；手动同步只作为维护入口。
- 解析并持久化五阶段预计耗时；缺省值由内容解析包统一估算。

退出标准：

- 自动测试确认 190 个唯一知识点全部导入。
- 每点的资料、考核、标准和状态字段完整。
- 二次导入幂等，用户字段不被覆盖。

## Phase 2：知识清单与学习工作区

目标：网站可用于日常学习。

任务：

- 左侧导航、今日页基础壳、知识列表和详情。
- Markdown 安全渲染、笔记编辑、附件证据。
- 自评掌握命令和状态审计。
- 资料筛选、领域筛选、状态筛选和搜索。
- 实现自定义视觉 Token、字体和响应式基础。
- 在 Vue 学习指南中补充响应式系统、computed/watch、composable、Vue Router、Pinia、Vue Query 和 Element Plus 的真实项目用法。

退出标准：

- 用户能从知识列表完成学习、保存笔记、自评掌握。
- 刷新后状态和编辑内容不丢失。
- 键盘主流程可用。

## Phase 3：日历、计划与打卡

目标：建立每日执行闭环。

任务：

- 真实的月/周/日视图。
- 从 48 周 CSV 和每日时间块生成每周 7 天、共 336 条计划。
- 按 15 分钟粒度把 190 个知识点拆成资料、练习、项目、考核和复测阶段；默认每日容量上限 390 分钟，周一至周日连续推进。
- 增加请假记录，并把当天及未来未完成学习计划原子顺延一天。
- 创建、拖拽、改期、完成、部分完成、跳过。
- 日复盘、周复盘和完成率。
- 今日页接入当天计划与待复测。

退出标准：

- 首次启动自动生成完整 48 周计划，旧计划自动升级且重复启动幂等。
- 打卡和改期历史可追踪。
- 7 天复测事件类型已准备好。

## Phase 4：知识图谱

目标：可视化能力结构和学习路径。

任务：

- 实现领域、知识点和关系 API。
- 实现 7 条能力主干、20 个领域的可展开体系脑图，并作为知识模块默认入口。
- 实现双环节点、领域折叠、搜索和聚焦路径。
- 实现图谱与列表状态同步。
- 实现项目应用和岗位技能缺口可切换图层。
- 提供移动端等价列表路径视图。

退出标准：

- 153 节点布局性能达标。
- 状态更新后节点立即变化。
- 图谱键盘与辅助信息可用。

## Phase 5：AI 考核 MVP

目标：完成问答与确定性题型的严格评分。

任务：

- 实现 Provider adapter、DeepSeek 环境配置和连接测试。
- 实现题目生成、会话、自动保存、交卷快照。
- 实现客观题确定性评分。
- 实现 DeepSeek JSON Output 评分、Zod 校验、服务端重算和错误恢复。
- 实现首次通过、复测、MASTERED 和月度抽测状态机。
- 建立 Fake provider 和 20 份 AI 回归答卷。

退出标准：

- 模型不能直接修改知识状态。
- 非 JSON、低置信度、提示注入和测试失败都不能自动通过。
- 首试通过自动生成复测，复测通过自动标记已掌握。

## Phase 6：求职支线

目标：岗位反馈能反向驱动学习。

任务：

- 岗位 CSV 导入、列表、看板和详情。
- 求职活动时间线、面试记录和日历同步。
- 岗位技能缺口关联知识点。
- 项目资产导入和结构化编辑。
- 求职漏斗、下一动作和每周复盘。

退出标准：

- 完成一次“面试反馈 -> 知识待办 -> 掌握 -> 缺口关闭”完整流程。
- 求职事件与学习事件在日历中可区分但统一管理。

## Phase 7：代码考核与项目证据

目标：让实践题具备可验证结果。

任务：

- 接入可选 Docker/Podman 隔离运行器。
- 实现 TS/JS 代码题、隐藏测试、超时和资源限制。
- 实现项目附件、测试报告和人工复核。
- 运行器不可用时安全降级。

退出标准：

- 不可信代码无法访问网络和宿主文件。
- 确定性失败不能被 DeepSeek 文字评价覆盖。
- 没有沙箱时绝不在宿主机执行答案。

## Phase 8：备份、硬化与发布

目标：可以长期使用而不会丢数据。

任务：

- SQLite 一致性快照、checksum、恢复预览和重启时原子恢复。
- 自动轮换备份和数据诊断。
- 全量 E2E、可访问性和性能验收。
- 模型配置、隐私说明和故障手册。
- 本地生产构建和一键启动脚本。
- 完成 Vue 学习指南，覆盖组件测试、E2E、构建和从 React 迁移思维的总结。

退出标准：

- 通过所有 E2E 场景。
- 从空数据库恢复后数据一致。
- 文档说明已知限制、升级和备份流程。
- 内容、耗时、计划算法和 API 变更已按开发文档同步矩阵更新，不保留旧口径。

## GLM-5 每阶段工作循环

1. 先读取当前阶段相关文档和现有代码。
2. 写出本阶段文件级计划与验收映射。
3. 先实现领域规则和测试，再实现 UI。
4. 每完成一个垂直切片立即运行相关测试。
5. 阶段结束运行 typecheck、test、build 和相关 E2E。
6. 更新实施状态文档，列出证据而不是笼统声称完成。
7. 验收未通过就留在当前阶段修复，不提前进入下一阶段。
