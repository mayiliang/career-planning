## 已知外部边界

1. 真实 AI thinking 取决于所选模型和兼容接口是否实际返回推理字段；自动化使用模拟流验证协议分离。
2. `pnpm content:links` 已确认 592 个本地链接无失效；`pnpm content:links:strict` 依赖可用网络和外部站点状态，本轮未取得严格联网复核结果，397 个远程唯一链接均不得据此宣称可达或失效。
3. Mermaid 支持多种图形，运行时体积较大，因此只在检测到闭合图形围栏时异步加载；TypeScript 站内执行器也保持独立大分块。
4. 系统没有内置公网账号认证，服务器部署必须使用私网、VPN 或认证网关。
5. Docker/Podman 服务端不可信代码执行器仍需独立网络隔离和逃逸测试；当前站内基础练习只提供本地 Worker 自检，它不是安全沙箱或服务端执行证明。
