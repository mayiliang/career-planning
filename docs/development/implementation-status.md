## 验收结论

Phase 0-8 已完成验收，并追加一轮面向真实使用体验的修复与扩充。当前系统以 Vue 3、Fastify 和 SQLite 为基础，已经形成“知识体系 → 学习资料 → 严格考核 → 状态更新 → 7 天学习计划 → 打卡复盘 → 求职校准”的本地闭环。

## DeepSeek 故障结论

原失败答卷并不是 API Key 无效：DeepSeek 已返回合法 JSON，但 `findings`、`criticalFailures` 和 `weaknesses` 使用了与本地 Zod Schema 不同的简写字段，导致系统进入 `MANUAL_REVIEW`。根因是旧提示词只给出了空数组，没有定义数组元素结构。

已完成修复：

1. 提示词提供完整 JSON 示例并明确所有数组元素字段不可省略。
2. JSON 语法正确但 Schema 失败时，把精确校验错误发回模型，自动进行一次只修结构、不改评分结论的修复。
3. 增加输出上限，保留截断、超时、429 和 5xx 重试处理。
4. `ERROR` 与 `MANUAL_REVIEW` 页面均提供“重新调用 DeepSeek 判题”。
5. 重判前原子清理旧结果，避免同一会话产生重复成绩。

为避免未经确认消耗额度或覆盖用户已有考核结果，本轮只做了无计费连接诊断和契约回归，没有自动触发一份新的计费判卷。用户可在原失败考核页点击“重新调用 DeepSeek 判题”完成最终真实模型验收。

## 主要交互改进

- 使用统一的深海军蓝导航、矿物浅色内容区、圆角卡片、清晰状态色和响应式底部导航。
- 知识清单使用双环掌握状态；脑图成为知识模块默认入口。
- 今日页不再只是事件列表：首屏直接呈现当前任务、完成度与学习证据入口，后续按行动时间线、知识队列、未来 7 天和复盘工作台组织。
- 关系图谱不再一次平铺全部节点：全局视图观察领域流向，局部视图查看领域包含与知识点学习顺序，并支持搜索聚焦、状态过滤、节点检查和双击打开。
- 学习计划默认进入周视图，每一天都是一份四段式“学习合同”，知识内容与严格考核、通过标准直接来自同一份知识库，不再依赖模糊的活动标题。
- 学习计划新增阶段、周目标、真实项目锚点、日检/周闸门方式和“当天、次日、7 天、30 天”复测节奏；知识重大更新后只同步尚未开始的模板事件。
- 知识详情直接展示“学习之前 / 当前节点 / 掌握之后”，并列出横向关联；前置未掌握只提示推荐顺序，不会阻止用户自主学习。
- 初始化按钮不再是正常使用的前置步骤，学习计划页直接显示系统自动生成状态。
- 月、周、日不再是占位切换；周视图固定生成 7 个日程栏。
- 设置页明确展示自动同步、自动备份、数据库、DeepSeek 和执行器状态，不回显 API Key。

## 运行与配置

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

不再需要手动运行数据库迁移或内容导入。

- 前端：`http://127.0.0.1:41731`
- 后端：`http://127.0.0.1:41730`
- DeepSeek：在 `.env.local` 配置 `DEEPSEEK_API_KEY`，模型可通过 `DEEPSEEK_MODEL` 修改
- 自动初始化：`AUTO_BOOTSTRAP=false` 可关闭
- 自动备份：`AUTO_BACKUP=false` 可关闭，间隔由 `AUTO_BACKUP_INTERVAL_HOURS` 控制
- 手动备份：`pnpm backup:create`
