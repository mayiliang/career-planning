## 本轮完成

- 用 `markdown-it` 统一替代手写 Markdown 解析器，增加 GFM 常用语法、脚注、标记、上下标、KaTeX、Mermaid、Highlight.js 和提示容器。
- 新建 `MarkdownRenderer.vue`，学习资料、知识笔记、AI 整理、通过标准、练习验证和掌握提示不再各自直接执行 `v-html`。
- 原始 HTML 默认关闭，输出经 DOMPurify 清洗；外部链接增加安全属性，仓库内不可访问的相对资料链接降级为普通文字，Mermaid 使用 strict 模式。
- 流式 Markdown 按 72ms 合并并在动画帧更新；增加 120 项 Markdown LRU、40 项 Mermaid SVG 缓存、动态 import 和修订号竞态保护。
- 笔记整理、题目提示、练习验证和 AI 判题四条服务链均识别 `reasoning_content/reasoning`，通过独立 SSE thinking 事件展示。
- 增加 `DEEPSEEK_THINKING_MODE=auto|enabled|disabled`；默认不强行发送供应商特有参数。
- thinking 以可折叠 Markdown 显示并标记“模型提供，可能不完整”，不持久化为笔记或评分依据。
- thinking 增加视口高度上限、独立滚动、自动跟随/暂停跟随、“回到最新”和完成后自动收起；笔记最终正文被截断时自动清空残稿并进行一次最终正文重试。
- 知识点资料页改为“资料全宽 + 练习横向等高卡片”，笔记中心及主要页面页头压缩为紧凑布局，减少首屏说明和不对称双栏造成的空间浪费。
- Nginx SSE 读取/发送超时调整为 360 秒并关闭代理缓冲和缓存。
- 重写产品、交互、架构、数据、AI、API、测试、Vue 和根 README；新增现代 Markdown/AI 流协议与服务器支持手册。
- 删除早期 GLM-5 生成提示词、已完成实施路线、固定 64 周个人计划、重复职业/成长路线和空的专题计划文档；改为一份自主学习路线。

## 已知外部边界

1. 真实 AI thinking 取决于所选模型和兼容接口是否实际返回推理字段；自动化使用模拟流验证协议分离。
2. `pnpm content:links` 需要网络，本轮没有重新执行全量远程链接检查；内容门禁与本地链接检查已通过。
3. Mermaid 支持多种图形，运行时体积较大，因此只在检测到闭合图形围栏时异步加载；TypeScript 站内执行器也保持独立大分块。
4. 系统没有内置公网账号认证，服务器部署必须使用私网、VPN 或认证网关。
5. Docker/Podman 服务端不可信代码执行器仍需独立网络隔离和逃逸测试；当前站内基础练习使用浏览器隔离运行区。
