## 本轮体系改革

- 从 16 个领域、153 点扩展为 20 个领域、190 点。
- 新增渲染与数据、实时与离线、图形与实验、国际化、身份隐私、AI 产品安全治理、架构领导力和后端/云素养。
- MCP 主线升级为 2026 协议和 TypeScript SDK v2，移除旧会话模型作为当前实现的表述。
- 修正浏览器内置 AI 能力检测语义，补充实验性和降级边界。
- 替换已知失效或迁移的 React、Sigstore、Ant Design、Copilot、SRE、技术写作、Nuxt 和 Docker 资料。
- 将学习计划从 23 周重构为 48 周，容量从强制填满改为每日最多 390 分钟。
- 修复 Windows 项目根目录判断和 CRLF Markdown 解析。
- 内容门禁新增资料数量、陈旧链接和换行兼容检查。
- 中文必读资料覆盖率提升至 190/190；`WEB-01` 移除 WAI-ARIA APG 英文必读资料并改用中文 MDN 语义、表单、ARIA 和 `dialog` 文档。
- 缺少稳定中文版的知识点均补充逐点中文核心讲义；保留的英文原文逐条标为“仅用于版本核验”，不作为必读或独立首考题源。
- 内容门禁升级为逐链接、逐讲义章节和逐考核边界检查，避免仅凭“每点有一份中文资料”掩盖英文必读资料。
