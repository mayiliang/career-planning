# 学习资料、笔记、练习与掌握指南

更新时间：2026-08-29

## 资料

每个知识点的资料应共同覆盖定义、机制、适用条件、边界/失败模式和验证方法。这里同时检查两个不同维度：每一份资料自身的主要正文与当前知识点直接相关的比例应不低于约 80%；多份资料组合后则应完整且不过度重复地覆盖上述学习目标。窄而深入、只负责一个子机制的页面可以合格；综合首页、目录页或只有少量相关段落的长文不能因为“提到过”该主题就作为当前资料。

中文资料是学习主入口；标准组织、项目官方规范/文档和官方发布说明是一手事实源，英文一手资料仅作版本核验，并必须有中文讲义覆盖其可考察内容。找不到合格中文外部资料时，应在 `chinese-guides/` 中编写完整的逐点中文讲义并链接到精确标题锚点。系统会将这种仓库内链接转换为站内资料页，学习资料、练习题源和掌握挑战均可直接打开对应章节；不得用未链接的其他章节冒充本知识点覆盖。

B01～B03 的主讲义和原子前置资料采用递归的直接依赖结构：一份资料的“学习前先确认”只列读懂当前正文不可缺少的直接前置，间接前置由被链接的下一份资料继续列出。不得在父资料里重复列出已经由直接前置包含的祖先，也不得形成循环依赖。前置区之外可以给出继续阅读或相关知识链接，但这些导航不能冒充硬前置。主讲义必须能从定义逐层推进到运行机制、成立条件、边界、失败模式、验证方法与工程取舍；短不是目标，压缩掉解释上下文或为了站内挑战倒推正文都视为不合格。

B01～B03 的美式发音只服务关键名词，不覆盖正文中的每个英文标识符。需要发音的术语应在首次定义处写成加粗的 `**中文（English term）**`；少数没有自然中文译名的核心名词可直接写成加粗英文。普通变量名、重复出现的 API 名称、链接文字和代码块不得因为含英文而自动添加发音。每次修改这三个批次的主讲义或其站内前置资料后，都必须运行 `pnpm content:check`；该命令会分别核对 B01、B02、B03 的资料范围、关键术语、离线音频和清单。检查提示缺失或过期时，在 Windows 上运行 `pnpm --filter @career-atlas/web pronunciation:generate`，再重新检查。

资料链接必须真实可达、标题与目标内容一致。逐条正文审读仍是相关性与质量判断的依据，链接可达、标题匹配或自动门禁通过本身都不能证明资料合格。挑战题要标注资料标题和具体段落/章节；不能要求用户依赖没有列出的知识回答。

内容合入前执行常规链接检查；发布或联网审计执行 `pnpm content:links:strict`，此时 404/410、本地文件/锚点失效和网络环境下无法确认都会阻断。演进中、实验性、框架特定、厂商特定和法域特定能力还要分别复核版本、支持矩阵、适用性与降级策略，并更新核验日期。

## 笔记

原始笔记使用 Markdown，支持标题、列表、任务、表格、链接、图片、脚注、代码、数学公式、Mermaid 图形、提示块和 thinking。知识点保存的笔记自动进入笔记中心，默认按知识体系顺序排列。

AI 整理会生成独立候选稿：

- 对照当前知识点资料检查明显错误和遗漏；
- 改善结构、中文表达、逻辑和排版；
- 把无法由资料确认的内容列为待确认；
- 流式展示模型 thinking 和候选正文；
- 永不覆盖原文，只有用户接受后才切换阅读版本。

## 学习完成

B01～B03 主讲义及其前置短文分别记录阅读进度。页面根据用户实际到达的正文位置保存历史最高值，超过 80% 时自动标记该资料“已看完”；返回知识点或打开相互引用的资料时，会显示未读、百分比或已看完。阅读记录只会向前推进，不能因为回到页面顶部而倒退。

资料“已看完”和知识点“已学完”是两个层次。前者表示已经浏览了某一份文档，后者仍由用户在完成资料与笔记后主动确认；二者都不声明已经掌握，也不要求先通过练习或挑战。

## 练习

练习只在能帮助理解时提供，必须具备：

1. 明确输入；
2. 必须提交的输出；
3. 可检查的完成条件；
4. 对应资料位置；
5. 站内编辑、执行/预览、保存和验证入口。

代码题应在隔离的浏览器运行区或经安全验证的执行器中运行。没有实际任务时不显示“项目”时间占位；纯理论知识可以只有案例辨析或没有实践题。

## 掌握挑战

- M1：初步理解。
- M2：引导应用。
- M3：独立完成，显示“已掌握”。
- M4：至少 7 天后完成变式，显示“稳定掌握”。

挑战完全可选，帮助逐级展开且不扣分，但会记录独立程度。题目应明确知识标签、要求、格式、输入输出、资料定位和推导过程。失败不撤销“已学完”或已有 M 等级。

## 路线与打卡

系统沿唯一直接后续连续推进，只在线路结束时提供方向选择。未选支线不会被视为放弃；暂缓内容可从知识体系恢复。

打卡记录当天实际学习的一个或多个知识点、时间和总结，不受每日任务或固定学习强度约束。
