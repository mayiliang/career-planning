# 知识资源审计口径

本目录按批次保存 20 个知识域、223 个知识点的逐点审计。权威清单来自 `docs/knowledge/knowledge-base/01-*.md` 至 `20-*.md` 的解析结果；报告不得自行增减、合并或重编号知识点。

## 报告批次与记录格式

报告文件固定为 `01-03.md`、`04-06.md`、`07-09.md`、`10-12.md`、`13-14.md`、`15-17.md`、`18-20.md`。每份报告以逐点 Markdown 主表记录本批次的每一个知识点；主表第一列必须是唯一的知识点代码。代码只能出现在所属领域的一个批次中，不能遗漏、重复或记录知识库外代码。

报告还必须把知识点映射到当前资料行的每个实际链接，可任选或混用两种机读格式：代码在第一列且同一行直接列出 Markdown 链接；或逐资源表将 Markdown 链接置于第一列、对应的反引号知识点代码置于第二列。逐资源表允许同一代码出现多行，不计作逐点主表的重复；逐点覆盖主表仍须每点恰好一行。审计记录中的链接集合须覆盖当前 `studyMaterial` 的全部 URL；匹配当前 URL 的记录不得标为“无法正文核验”“未正文核验”“未核验”或“无法读取”。每个当前 URL 至少要有一条非删除映射行使用机读字段 `正文相关度≥80%；覆盖分工=...`：其中“正文相关度”是该资源自身正文中与本知识点直接相关的内容占比，不是该资源对知识点要求的覆盖比例；“覆盖分工”说明该资源在组合资料中负责的定义、机制、边界、验证或排错部分。当前映射行若另行明确声明正文相关度或相关度百分比低于 80%（包括下界低于 80% 的区间），自动检查必须失败。当前不可达且无法核验的外链应删除、替换，或先由足量本地中文讲义补齐后从当前学习资料中移除。报告可保留当前资料外的历史链接、低相关性判断及其未核验状态，但该链接所在行必须明确标注“删除”，且不能用于满足当前 URL 映射，也不参与当前正文相关度门禁。

每个报告须写明：

- `verifiedAt`：本次实际核验日期（不得把资料发布日期当作核验日期）。
- `status`：逐点结论，使用下列受控类别之一。
- 逐资源相关性判断、合并后的覆盖范围、实践/考核与本次修改或遗留风险。

状态类别：`通过`、`有条件通过`、`需修订`、`阻塞`。`有条件通过`必须说明条件、责任人或复核时机；`阻塞`必须说明阻塞来源，不能用“链接暂时不可达”替代内容失效的结论。

## 资源判定标准

每个知识点至少应有一项中文主学习源：项目内中文讲义的精确 Markdown 锚点，或可直接阅读的中文官方/一手页面。英文原文可以保留用于版本、规范或实现差异核验，但每个非中文外链项后必须紧随“英文原文，仅用于版本核验”的明确标记（允许等价中英文标点）；资料行还须声明英文不作为必读或独立首考题源，严格考核须明确英文不得独立命题。英文资料不能成为中文材料的替代品。

同一点的资源 URL 归一化后不得重复（外链忽略片段、规范化主机名/查询顺序和末尾斜杠；本地 Markdown 链接规范化相对路径与锚点）。如果没有合格的中文外部主源、仅由本地中文讲义承担首学内容，则只计算该点资料行实际链接到的讲义章节正文，合计至少 700 个字符；未链接章节不得计入。700 字符只是防止空锚点、提纲式讲义或误连章节的最低完整性防线，不证明资料有 80% 相关性或足够的教学质量。

审计每一项资源时，以“该资源能否支持本知识点”为单位判断，不以站点权威性、链接可达性或资源数量代替相关性。单项资源应对该点约有 80% 以上的直接相关性；低于此阈值时，应删除、降为可选核验，或在报告中明确其只覆盖的窄范围。该阈值是人工内容判断，不是自动化测试可以证明的分数。

同一点的资源组合应覆盖：定义、机制、使用条件、边界/反例，以及验证或排错方式。资源可以分工覆盖这些方面，但报告必须说明组合后的缺口；不能把相邻知识点的通用资料算作本点覆盖。

## 实践、掌握与结论

严格考核或实践至少明确：输入/约束、最小输出或交付物、检查或验证方法，以及调试/受限排错情境。通过标准应描述可复核证据，并限定在本点列出的资料、题目输入和产出范围内；不得用未列资料、隐含项目背景或泛化经验替代证据。

自动检查会验证权威数量、代码唯一性、学习资料/覆盖说明/通过标准是否存在、中文主源、英文非唯一性、本地 Markdown 文件与锚点、考核中的输出/排错/验证信号、七份报告的代码集合一致性，以及每个当前 URL 的报告行是否声明 `正文相关度≥80%；覆盖分工=...` 且没有自相矛盾的低相关度数字。这个机读字段只证明报告声明完整、一致，不能把声明本身当作资料正文事实。自动检查也不能证明资料真实、页面仍准确、资源实际达到约 80% 正文相关、中文解释质量、跨资源语义覆盖完整，或练习在真实环境确实有效。这些项目必须由审计者阅读页面、运行实践并在报告中记录依据与遗留风险。

远程链接的网络失败、反爬或地区限制只表示本次无法自动确认可达性，不自动等同于资料错误或法律/规范失效；应分别记录 HTTP 结果、最终 URL、核验时间和需要人工复核的原因。
