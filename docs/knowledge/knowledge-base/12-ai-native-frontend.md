# 12 AI 原生前端与模型应用工程

这一领域覆盖前端工程师构建 AI 产品时真正需要负责的交互、协议、可靠性与安全能力。重点不是背 Prompt 技巧，而是把不确定的模型能力变成可观测、可恢复、可评估的产品功能。

### 模型交互与结构化契约
