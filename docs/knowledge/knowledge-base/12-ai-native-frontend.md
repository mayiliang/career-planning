# 12 AI 原生前端与模型应用工程

这一领域覆盖前端工程师构建 AI 产品时真正需要负责的交互、协议、可靠性与安全能力。重点不是背 Prompt 技巧，而是把不确定的模型能力变成可观测、可恢复、可评估的产品功能。

- 通过标准：adapter 有运行时校验、AbortSignal、错误分类、能力协商和多 Provider 契约测试；请求状态、请求 ID、版本与脱敏错误可回放，未知结果不盲重试；Prompt 资产可追踪到 owner、模型/版本、评测和发布记录并可回滚；不可信上下文与高优先级指令隔离；密钥不暴露到浏览器。评估边界：只展示一次补全成功、只有自然语言 Prompt 文件或把供应商私有字段当通用协议不能通过。 证据映射：状态/序号/幂等与租户边界=事件记录；成功与失败收敛=固定夹具自动化回归；版本、授权与恢复=审计/前后快照。否决项：无固定夹具、缺会话或租户身份、把未知结果盲重试，或只演示成功界面。
