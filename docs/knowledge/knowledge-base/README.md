# AI 时代高级前端知识掌握清单

更新时间：2026-07-28

这里是职业成长计划的执行核心。体系包含 **20 个领域、190 个唯一知识点**，覆盖 Web 基础、双框架应用、数据与实时协作、工程质量、部署云基础、AI 应用、Agent/MCP、浏览器本地 AI、隐私安全、产品实验、架构领导力和职业影响力。

每个知识点都有稳定编号、官方或一手学习资料、覆盖范围、严格考核、通过标准及“资料精读、机制练习、项目产出、严格首考、7 天复测”五阶段耗时。资料选择和更新规则见[学习资料与耗时使用指南](../learning-resource-guide.md)。

## 完成状态

- `[ ] 自评已掌握`：已完成资料与实践，不看资料也能解释机制、适用条件和失败边界。
- `[ ] 已通过严格考核`：首次考核通过，至少 7 天后的闭卷复测仍通过，并留下可追溯证据。
- “工作中用过”“看懂了”“AI 帮我写出来了”都不能直接视为掌握。
- 证据可以是答卷、测试、代码、ADR、性能/安全报告、部署记录或录屏。

## 能力层级

- 核心必修：01、02、03 或 11 至少一套主框架、05、06、07、09、12、15、17、19、20。
- 岗位必修：根据目标岗位选择 React/Vue、Umi/Ant Design、组件平台、H5/Hybrid、Node/BFF 等方向。
- 前沿专项：13、14 中的 MCP、Agent 与浏览器本地推理。必须学习兼容和降级，不把实验 API 当作通用生产能力。
- 第二框架和企业技术栈用于扩展边界，不应挤占核心工程、数据、安全和 AI 产品能力。

“完整体系”指能力地图覆盖完整，不意味着每个求职者必须以相同深度掌握全部专项。系统的完整路线会安排 190 点；个人可以通过岗位画像调整专项深度，但不能跳过其硬前置。

## 推荐使用流程

1. 从 48 周计划读取本周知识和到期复测；推荐路线只是学习编排，只有图谱中显式标为 `PREREQUISITE` 的关系才是硬前置。
2. 精读资料并完成最小实验，写出机制、边界、反例和仍待验证的问题。
3. 将知识迁移到真实项目，再完成严格首考。
4. 使用[考核记录模板](assessment-record-template.md)保留逐题依据。未通过时进入补学，不修改评分标准。
5. 首次通过至少 7 天后闭卷复测；复测通过才标为严格掌握。
6. 每月随机抽取已掌握知识点复测；失败则进入重新学习状态。

命题必须遵守资料强关联原则：考核内容应能由列出资料直接支持或一跳推导；若考核要求超出资料，先补资料再出题。

## 时间与计划原则

- 完整路线为 **48 周**：前 44 周覆盖全部知识合同，后 4 周用于证据整合、生产演练、综合项目和毕业答辩。
- 每日学习容量上限为 390 分钟。计划不再为了“填满一天”伪造项目时间，也不通过压缩考核来赶进度。
- 首考完成后，复测自动进入至少 7 天后的到期队列，并优先于新知识。
- 前 44 周的总容量为 120,120 分钟，可覆盖当前全部知识点的显式学习和复测预算，并保留少量缓冲。
- 实际耗时用于后续校准；超载任务顺延，不降低通过标准。
