# 前端知识掌握清单

更新时间：2026-07-22

这里是整个职业成长计划的执行核心。每个知识点都有稳定编号、学习资料、考核任务、通过标准和两个可勾选状态。学习资料不限于文本或视频，也可以是规范、实验、真实项目片段、源码、工具文档或本地笔记；唯一硬约束是必须覆盖该知识点的核心机制、边界、反例、练习和考核依据。

所有知识点还带有“资料精读、机制练习、项目产出、严格首考、7 天复测”五阶段耗时，可直接用于每日负载计算。当前 153 个知识点已全部补齐覆盖范围、命题边界、评估边界和显式预计耗时；连续课程、官方资源主干和耗时覆盖方法见[学习资料与耗时使用指南](../learning-resource-guide.md)。

## 状态定义

- `[ ] 自评已掌握`：已阅读指定资料、完成示例，不看资料也能独立复述和应用。
- `[ ] 已通过严格考核`：已按[统一考核规则](00-assessment-rules.md)完成资料可追溯的闭卷问答、最小实践或受限排错任务，达到通过线并完成延迟复测。
- 不允许因为“工作中用过”或“看懂了”直接勾选通过。
- 每次考核必须留下证据：答卷、代码、项目链接、性能报告、设计文档或录屏之一。

## 推荐使用流程

1. 从 23 周计划中确定本周主题，按日历给出的阶段任务推进；一个知识点可跨多天完成，同一天也可承接多个知识点的不同阶段，周一到周日都按同一强度推进。
2. 学习并确认可以独立复述、应用后勾选“自评已掌握”，同时记录来源和自己的示例。
3. 至少间隔 24 小时再参加首次考核，避免把短时记忆当成掌握。首次考核必须从资料定位、概念解释、小例子推导、受限排错和学习复述逐步推进，答案应能从学习资料直接查到或一跳推导。
4. 将结果写入[考核记录模板](assessment-record-template.md)，未通过时只记录逐题薄弱项、参考答案和下一步补学动作，不勾选“已通过严格考核”。
5. 首次通过 7 天后闭卷复测；复测仍达到标准，才勾选“已通过严格考核”。
6. 每月随机抽取 20% 已通过知识点复测，失败则取消对应勾选。

命题时必须遵守资料强关联原则：首次考核不得使用学习资料未列出、题目未点名的框架或项目场景作为主要依据；参考答案和评审意见必须能回指到资料、题目依据或通过标准。

## 时间安排原则

- 日历按知识点的预计分钟数而不是知识点数量分配周一至周日的阶段任务，尽量保持每天负载接近。
- 默认每日学习容量为 540 分钟，生成计划时每天预计投入不低于 500 分钟；知识点较少的后期周会用项目整合、闭卷答辩和复盘任务补足强度。
- 单日预计投入超过当天事件容量时显示超载提醒，优先顺延低优先级任务，禁止用压缩严格考核来“赶进度”。
- 预计耗时用于计划，打卡的实际耗时用于校准；计划容量与预计投入是两个不同指标。
- 知识体系或 23 周模板大改后，使用“系统与数据 -> 学习进度重置”按最新版模板重新开始；该动作只清学习进度，不删除求职岗位、项目资产和备份。
