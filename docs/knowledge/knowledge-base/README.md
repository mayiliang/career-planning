# 前端知识掌握清单

更新时间：2026-07-13

这里是整个职业成长计划的执行核心。每个知识点都有稳定编号、学习资料、考核任务、通过标准和两个可勾选状态。

## 状态定义

- `[ ] 自评已掌握`：已阅读指定资料、完成示例，不看资料也能独立复述和应用。
- `[ ] 已通过严格考核`：已按[统一考核规则](00-assessment-rules.md)完成闭卷问答、编码或实战任务，达到通过线并完成延迟复测。
- 不允许因为“工作中用过”或“看懂了”直接勾选通过。
- 每次考核必须留下证据：答卷、代码、项目链接、性能报告、设计文档或录屏之一。

## 推荐使用流程

1. 从 16 周计划中确定本周主题，只选择对应文件中的 3-5 个知识点。
2. 学习并确认可以独立复述、应用后勾选“自评已掌握”，同时记录来源和自己的示例。
3. 至少间隔 24 小时再参加首次考核，避免把短时记忆当成掌握。
4. 将结果写入[考核记录模板](assessment-record-template.md)，未通过时只记录薄弱项，不勾选“已通过严格考核”。
5. 首次通过 7 天后闭卷复测；复测仍达到标准，才勾选“已通过严格考核”。
6. 每月随机抽取 20% 已通过知识点复测，失败则取消对应勾选。

按统一考核规则出题，包含闭卷问答、限时编码和项目追问。
