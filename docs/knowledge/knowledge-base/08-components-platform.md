- 严格考核：首考题 1（资料定位）：只允许使用列出的中文资料，定位一致性、及时反馈、表单、错误和无障碍约束；首考题 2（机制解释）：闭卷解释用户目标如何转成任务流、界面状态、反馈和可验证的成功标准，并区分可用性、无障碍和视觉美观；首考题 3（最小产出）：为导入审批、异步生成或复杂配置流程制作任务流和交互原型，完整实现八类状态，邀请目标用户完成不带提示的任务并迭代两轮；首考题 4（受限排错）：根据录屏、任务完成率、错误率和观察笔记定位找不到入口、误操作、错误不可恢复或反馈不明确的问题；首考题 5（学习复述）：3 分钟向产品、设计和工程师说明取舍与验证结果。命题边界：不得用个人偏好、截图还原度、点击量或 AI 自评替代真实任务和用户证据。
- 通过标准：核心任务的入口、状态和恢复路径完整；关键操作可撤销或二次确认；文案说明下一步；原型测试任务中立且记录事实与解释；至少一项改动由可用性证据驱动并完成复验；保持键盘、读屏、缩放和 reduced-motion 可用。评估边界：只完成视觉稿、只让同事随意体验或把无障碍等同于全部 UX 不能通过。
