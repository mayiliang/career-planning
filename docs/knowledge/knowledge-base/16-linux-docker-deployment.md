# 16 Linux、Docker 与前端部署交付

这一领域把前端能力从“本地开发完成”推进到“可打包、可部署、可排障、可回滚”。你需要掌握 Linux 基础、Docker 镜像、Compose 编排、Nginx/CDN 静态资源、CI/CD 制品和生产排障，才能独立完成 Web/H5 项目的交付闭环。
