### 身份与授权

## IDENTITY-01 Cookie、Session、Token 与浏览器身份边界

- [ ] 自评已掌握
- [ ] 已通过严格考核
- 学习资料：[中文学习讲义：identity-01](../chinese-guides/content-audit-18-20.md#identity-01)、[MDN Cookie](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Guides/Cookies)、[MDN CHIPS 分区 Cookie](https://developer.mozilla.org/zh-CN/docs/Web/Privacy/Guides/Third-party_cookies/Partitioned_cookies)。覆盖范围：中文讲义承担 Cookie、服务端 Session、Bearer Token 的完整生命周期及第三方限制、新身份能力的成熟度与回退；两份 MDN 中文页核验 Cookie 属性和 CHIPS 分区机制。XSS/CSRF 攻击数据流和危险 sink 归 `SEC-01`。
- 严格考核：挑战类型：CODING；题源包含《中文学习讲义：identity-01》《MDN Cookie》《MDN CHIPS 分区 Cookie》；首考题 1（资料定位）：只允许使用《中文学习讲义：identity-01》《MDN Cookie》《MDN CHIPS 分区 Cookie》，中文讲义定位会话生命周期与第三方限制验证，MDN 页核验 Cookie 属性与 CHIPS 分区机制；首考题 2（机制解释）：以登录、续期、退出、顶层/iframe 与 Immediate UI 回退画出身份链；说明 Chrome 专属能力或 JWT 不能替代通用会话和隐私边界；首考题 3（最小产出）：fixture 固定为顶层 `app.example`、嵌入 `widget.example`、`sid` HttpOnly Cookie、一次无用户手势调用、第三方 Cookie 禁用和 `NotAllowedError` 响应；实现 HttpOnly 会话、CSRF 防护、CHIPS/Storage Access/FedCM 回退及受手势保护的 Immediate UI；提交 Cookie 属性表、能力检测分支、退出吊销记录，并以顶层/嵌入/禁用/拒绝四组网络测试验证；预期：凭证不暴露、嵌入限制下可回退且退出后任何旧请求被拒绝；首考题 4（受限排错）：给定登录后 session ID 未轮换、嵌入页 CHIPS 分区键错误、无用户手势的 `NotAllowedError` 日志；仅允许候选：会话轮换、分区 Cookie 属性、Immediate UI 手势闸门；分别以 Set-Cookie、分区请求头和调用时序证伪，提交最小修复及顶层/嵌入回归记录；首考题 5（学习复述）：比较一方会话、分区 Cookie、Storage Access、FedCM 与 Immediate UI。复测变式：仅禁用第三方 Cookie，保持顶层会话、用户手势和账号不变；预期嵌入路径回退但标准登录可发现；提交请求头、能力分支和登录回归录屏。命题边界：不得把 JWT 当天然安全或可吊销，不得用指纹追踪绕过隐私，也不得把 Chrome Immediate UI/Digital Credentials 当通用认证基线。
- 通过标准：敏感凭证不暴露给普通脚本；Cookie 配置合理；第三方访问由明确用户动作和最小范围触发；退出与吊销有效；Immediate UI 只在能力检测和用户手势后调用，无凭证/不支持时保留可发现的标准登录；禁用第三方 Cookie 或不支持 FedCM/Immediate UI/Digital Credentials 时仍可用；实验/专属/草案能力在 UI、遥测和发布中标注成熟度；证据：以上每项须由最小产出的版本化设计/实现、原始测量或演练记录逐项对应；否决项：缺任一证据、只展示 happy path 或无法复现。评估边界：只验证顶层登录、把 `NotAllowedError` 显示为账户错误或把观察项作为必经路径不能通过。
- 预计耗时：资料 90 分钟；练习 150 分钟；项目 135 分钟；考核 90 分钟；复测 75 分钟

- 通过标准：①码流+PKCE 和各声明校验齐全（证据：五组契约测试）；②Scope 与失败边界最小化（证据：配置/日志）；③退出/刷新不复活凭证（证据：复测记录）。评估边界：仅依据本点学习资料、题目固定输入和可复核产出评估。否决项：只信 SDK 成功、接受宽泛回调或称草案已发布均不通过。
- 预计耗时：资料 90 分钟；练习 150 分钟；项目 135 分钟；考核 90 分钟；复测 75 分钟

## AIPROD-02 高风险自动化分级、失败 UX 与 Human-in-the-loop

- [ ] 自评已掌握
