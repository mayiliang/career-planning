# 13 Agent、MCP 与 AI 工具协议

这一领域把“会调用模型”升级为“能设计可靠 Agent 系统”。前端工程师需要理解工具协议、状态、审批、长任务和可观测性，才能做好 Agent 产品的交互层与工具层。

- 通过标准：不会把 while(true) 当 Agent；每一步可审计；停止与恢复确定，恢复前重新核验权限/批准且不重放未知写入；用户能看到当前目标、动作和剩余预算；状态机快照、停止日志和恢复测试为可复核证据。否决项：缺少与「Agent Loop、计划与停止条件」直接对应的可复核产出，或用资料外经验绕过通过标准，均不能通过。评估边界：仅评估循环、停止与恢复，不以模型回答质量代替状态控制证据。

- 通过标准：每个 2026 HTTP POST 的 `Accept` 同时列出 `application/json` 与 `text/event-stream`，客户端可处理两类响应且不完整 header 夹具会失败；请求可落到任意实例；状态以显式 handle 或业务存储承载；版本分支可测试；远程服务有 Origin、Host 和认证校验。否决项：只让旧 SDK 示例运行、只支持一种响应媒体类型或未验证 header 失败不能通过。评估边界：仅评估 MCP 2026-07-28 Streamable HTTP、stdio 与兼容，不把移除的会话字段作为主实现。
