# 项目经验资产库

> 本页是个人实践证据索引，不是知识点的权威资料或通用考核前置。标记“待完善”的项目不得作为首考题源；通用考核必须随题提供完整、匿名、可复现的 fixture。项目完成后可把它作为自选练习、作品集或能力举证材料。

更新时间：2026-07-13

用途：把过去 5 年参与和维护的项目沉淀成可复用资产。这里不是流水账，而是服务长期成长、简历、面试、晋升和技术方案写作的材料库。

## 使用规则

- 每个项目都要写出“业务背景、技术难点、我的方案、结果、反思”。
- 优先写你参与最深、最能体现能力的模块，不追求覆盖所有页面。
- 每个项目都准备 3 个版本：30 秒简历版、2 分钟面试版、5 分钟深挖版。
- 每个项目都要绑定至少 1 个成长主题，例如 React 性能、业务建模、H5 兼容、组件库、工具化。

## 优先补齐的 4 个代表作

### 1. `gungnir-web`：大型中后台代表作

建议选择模块：

- `CampusJob`
- `Workspace`
- `Layout` / 权限菜单
- 自动表单/自动表格/导入导出相关公共组件

必须讲清楚：

- 业务对象和状态流是什么。
- 权限、路由、菜单、接口如何串起来。
- 复杂表单/表格/详情/审核操作如何拆分。
- 遇到接口变更、字段展示、导入导出、权限差异时如何保证稳定性。

可转化能力：

- React + Umi/Max + AntD 中后台
- 业务建模
- 权限流和审批流
- 组件抽象
- 工程质量

### 2. `gungnir-h5` 或 `digitalteacher-h5`：H5 代表作

建议选择模块：

- 企业微信/钉钉入口页面
- 视频/地图/签名/移动表单
- AI 问答或课程资料相关页面

必须讲清楚：

- H5 页面和 Web 中后台的差异。
- 移动端适配、键盘、滚动、安全区、性能如何处理。
- 企业微信/钉钉 SDK、鉴权、环境差异如何排查。
- 复杂媒体或地图能力如何落地。

可转化能力：

- H5/Hybrid
- 移动端性能
- 企业应用集成
- 多媒体能力

### 3. `digitalteacher-web` / `aiui`：AI 内容平台代表作

建议选择模块：

- AIUI 聊天组件
- Markdown/公式/代码高亮
- PDF/视频/课程资料
- 问答反馈或预习研讨

必须讲清楚：

- AI 场景下前端状态、消息、流式/异步交互如何设计。
- 内容渲染如何处理安全、性能和可扩展性。
- 组件如何做 API 设计和版本管理。

可转化能力：

- AI 产品前端
- 组件库
- 内容渲染
- 用户体验

### 4. `get_apidoc`：工具化代表作

必须讲清楚：

- 为什么要做这个工具。
- MCP 工具输入输出如何设计。
- YAML/OpenAPI 如何解析。
- 类型推断、缓存、错误处理如何做。
- 这个工具如何减少接口查询、类型判断、代码生成的重复劳动。

可转化能力：

- Node/TypeScript 工具开发
- MCP
- 接口治理
- 研发提效
- AI 辅助研发
