# AI 时代高级前端能力体系

更新时间：2026-07-29

本体系把高级前端定义为：能够在复杂约束下，从产品判断、架构设计、实现验证到生产交付，对 Web 与 AI 用户体验结果负责的人。

## 三层能力模型

### 核心必修

- Web 平台：HTML/CSS、JavaScript、复杂度、常用算法、前端大数据、TypeScript、浏览器、网络、系统调试、Web Components、可访问性、跨源隔离和安全。
- 应用开发：React、Vue、中后台、业务对象、状态、权限、表单、接口与异常边界。
- 工程质量：Git 对象与协作、模块与构建、包管理、测试、CI/CD、可观测性、供应链、发布，以及前端平台工程与 Golden Path。
- 数据与体验：交互设计、可用性验证、复杂编辑器/输入法、渲染策略、Server State、本地优先数据与同步、实时连接、离线、性能、H5/Hybrid。
- 生产交付：Node 运行时与 HTTP/BFF 服务、Linux、Docker、Nginx/CDN、部署、回滚与基础设施排障。

### 岗位专精

- 组件库、设计系统、配置化平台、微前端、嵌入式 SDK/第三方宿主、多租户隔离、浏览器扩展、桌面 Web 容器和跨平台原生/小程序边界。
- 图形、可视化、专业 Web 音视频管线、内容处理、技术 SEO、国际化和兼容性。
- 产品埋点、Feature Flag、A/B 实验与数据质量。
- 实时协作、冲突解决、GraphQL、边缘运行时和 PWA。

### AI 原生与高级影响力

- AI 产品判断、流式交互、结构化输出、会话记忆、Generative UI、复杂 AI 创作编辑器、MCP Apps、实时多模态/语音、RAG、评估、成本与信任体验。
- Agent Loop、MCP 2026、工具契约、任务、授权、审计和故障恢复。
- 浏览器本地推理、通用 WebAssembly、WebGPU/WebNN、Worker、模型缓存、Agent 可操作 Web、WebMCP、隐私和能力降级。
- AI 辅助研发、浏览器运行时证据调试、验证、评审、提示词资产、生成式 UI 与团队治理。
- 架构质量属性、ADR、渐进迁移、成本与可靠性、后端/云素养、技术领导力。

## 顺序与前置关系

“建议先学”不等于“学不会后项”。系统只把会造成概念、实现或安全断层的关系设为硬前置，例如：

```text
JavaScript 运行模型 -> TypeScript 建模 / React 渲染
JavaScript 值与集合 -> 复杂度 -> 数据结构与算法 -> 大数据 UI / Server State / 可视化
JavaScript 对象语义 -> 迭代协议与 Proxy/Reflect -> Vue 响应式边界
浏览器渲染/事件/存储 -> 页面生命周期与多标签协同 -> 性能观察 / PWA
Git 对象与暂存区 -> 分支合并与冲突 -> 协作、PR 与 Agent worktree
Git 提交图 + 浏览器/网络证据 -> 系统化调试 -> 性能和生产可观测性
React 组件与状态 -> Hook 规则 -> Effect 外部同步
HTTP 与缓存 -> Server State / 实时连接 /渲染策略

语义 HTML -> 可访问性 -> UX / AI 信任体验
浏览器输入/选择区 + 内容 AST -> 复杂编辑器 -> AI 创作与协作
OpenAPI/DTO -> 消费者驱动契约测试 -> 发布回滚 -> 生产可观测性
Git/构建/测试/发布/可观测性 -> 前端平台工程与 Golden Path -> 技术领导力
OAuth/OIDC -> MCP 授权安全
浏览器与 CSP -> 跨源隔离 / iframe 权限 -> WebMCP
构建产物 + Web Components + 跨源隔离 -> 嵌入式 SDK / 第三方宿主
MCP 核心能力 -> MCP Apps / Agent 工具契约 -> A2A 跨 Agent 协作 -> Agent 安全
版本化消息与 MCP Apps -> AG-UI / A2UI / MCP Apps 互操作
AI 产品、身份与隐私判断 -> AI 应用实现 -> 会话状态 -> RAG -> 长期记忆治理
```

框架之间、OpenAPI 与 GraphQL、验收标准与质量门禁等可以相互启发但不构成单向阻塞，建模为“相关”关系。

## 掌握标准

一个知识点只有同时满足以下条件才算掌握：

- 能从至少两份资料定位依据，并说明资料版本和适用边界。
- 能解释关键机制、失败模式、反例和取舍。
- 能完成最小实现或故障诊断，并留下可复核证据。
- 能迁移到真实项目，而不是只复述教程示例。
- 首考达到 80 分且无关键否决项。
- 至少 7 天后完成变式复测；失败后重新学习并再次复测。

统一评分规则见[考核规则](knowledge-base/00-assessment-rules.md)，资料选择见[学习资料指南](learning-resource-guide.md)。

## 维护边界

该体系覆盖稳定能力，不追求收录所有库、云厂商和模型。新增知识点必须满足至少一项：

- 能力已成为高级前端常见职责；
- 能力改变了前端架构、安全或交付边界；
- 能力在多个框架或厂商之间可迁移；
- 能力可以通过项目和考核形成可靠证据。

只代表短期热度、单一产品操作或可由现有知识点自然推导的内容，不单独立项。
