# 后续学习资料补充目录

Career Atlas 内置 AI 助手会先检索现有知识点和中文讲义。只有同时满足以下条件时，才会登记候选知识点：

1. 站内没有足够相关的知识点；
2. 用户疑问合理，并且属于“AI 时代前端高级工程师”培养范围；
3. AI 能给出明确的知识点名称、缺口理由和建议覆盖范围。

本地运行时的候选文件保存在数据目录下的 `learning-material-supplements/pending`。Windows 单机版默认位于 `%LOCALAPPDATA%\CareerAtlas\data\learning-material-supplements\pending`，文件名只使用安全的英文标识，正文为中文 Markdown。

## 每次更新前的检查清单

- 逐个阅读待处理 Markdown，不依据标题或关键词草率判断。
- 与知识库现有知识点和讲义全文比对，合并重复候选。
- 判断它应是新知识点、既有讲义补充、前置概念讲义，还是不纳入路线。
- 若纳入，补齐中文学习资料、重要专有名词的中英双语解释、掌握挑战与站内练习。
- 完成内容审计与链接检查后，在候选 Markdown 与本次发布记录中写明“已补充”或“已忽略”及理由，避免同一缺口被重复处理。
